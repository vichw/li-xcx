# 会员到期提醒功能调试指南

## 🐛 问题现象

用户登录了一个已过期的学生账号，但没有显示到期提醒弹窗。

## 🔍 调试步骤

### 1. 查看控制台日志

打开微信开发者工具的控制台（Console），查看以下日志输出：

#### 关键日志信息

```
========== 会员到期检测开始 ==========
userInfo: { ... }
membershipEndDate: "2025-01-10"
remainingCount: 0
会员类型: "年卡"
✓ 检测到年卡会员，开始检查到期情况
--- 年卡会员到期检测 ---
membershipEndDate 参数: "2025-01-10"
userInfo.membership_end_date: "2025-01-10"
当前时间: ...
到期时间: ...
剩余天数: -5
🔴 会员已过期，显示弹窗
========== 会员到期检测结束 ==========
```

### 2. 检查关键数据

根据控制台日志，检查以下几个关键点：

#### 检查点1：userInfo 是否存在

**日志位置**：`userInfo: { ... }`

**可能问题**：
- 如果显示 `userInfo: null` 或 `userInfo: undefined`
- **原因**：用户数据未加载完成
- **解决方案**：检查 `loadUserData` 函数是否正确执行

#### 检查点2：会员类型是否正确

**日志位置**：`会员类型: "年卡"` 或 `会员类型: "按次"`

**可能问题**：
- 显示 `会员类型: undefined`
- 显示 `会员类型: ""`（空字符串）
- 显示其他值，如 `"year_card"` 或 `"count_card"`

**解决方案**：
```javascript
// 检查数据库中 membership_type 字段的值
// 必须是中文：
// ✅ "年卡" - 正确
// ✅ "按次" - 正确
// ❌ "year_card" - 错误
// ❌ "count_card" - 错误
// ❌ "" - 错误
```

#### 检查点3：membershipEndDate 是否存在

**日志位置**：`membershipEndDate: "2025-01-10"`

**可能问题**：
- 显示 `membershipEndDate: undefined`
- 显示 `membershipEndDate: ""`
- 显示 `membershipEndDate: null`

**原因**：
- `onShow` 函数中的 `formatDate` 可能返回了空值
- `userInfo.membership_end_date` 本身就是空的

**解决方案**：
```javascript
// 检查 userInfo.membership_end_date 的原始值
console.log('原始到期日期:', userInfo.membership_end_date);

// 确保格式正确：
// ✅ "2025-01-10T00:00:00.000Z" - ISO格式
// ✅ "2025-01-10" - 日期字符串
// ❌ null
// ❌ undefined
// ❌ ""
```

#### 检查点4：日期格式是否正确

**日志位置**：
```
membershipEndDate 参数: "2025-01-10"
userInfo.membership_end_date: "2025-01-10"
当前时间: Mon Jan 15 2025 10:00:00 GMT+0800
到期时间: Thu Jan 10 2025 00:00:00 GMT+0800
剩余天数: -5
```

**可能问题**：
- `到期时间` 显示 `Invalid Date`
- `剩余天数` 显示 `NaN`

**解决方案**：
```javascript
// 确保日期格式可以被 new Date() 解析
// ✅ "2025-01-10"
// ✅ "2025-01-10T00:00:00.000Z"
// ✅ "2025/01/10"
// ❌ "10-01-2025" (格式错误)
// ❌ "2025年1月10日" (中文格式)
```

### 3. 常见问题排查

#### 问题1：日志显示"未识别的会员类型"

**日志**：
```
会员类型: "year_card"
⚠️ 未识别的会员类型: year_card
```

**原因**：数据库中 `membership_type` 字段不是中文

**解决方案**：

**方式A：修改数据库数据（推荐）**
```javascript
// 在数据库中将 membership_type 改为中文
// year_card → 年卡
// count_card → 按次
```

**方式B：修改代码适配英文字段**
```javascript
checkMembershipExpiry() {
  const membershipType = userInfo.membership_type;
  
  // 兼容英文和中文
  if (membershipType === '年卡' || membershipType === 'year_card') {
    this.checkYearCardExpiry(userInfo, membershipEndDate);
  }
  else if (membershipType === '按次' || membershipType === 'count_card') {
    this.checkCountCardExpiry(userInfo, remainingCount);
  }
}
```

#### 问题2：日志显示"日期数据不完整"

**日志**：
```
--- 年卡会员到期检测 ---
membershipEndDate 参数: undefined
userInfo.membership_end_date: undefined
❌ 日期数据不完整，跳过检测
```

**原因**：
1. `onShow` 中的 `setData` 没有设置 `membershipEndDate`
2. `userInfo.membership_end_date` 本身就是 `null` 或 `undefined`

**解决方案**：

**检查 onShow 函数**：
```javascript
onShow: function () {
  if (this.data.isLogin) {
    this.loadUserData(() => {
      // ...
      
      const formatDate = (dateStr) => {
        if (!dateStr) return ''; // ⚠️ 这里返回空字符串会导致检测失败
        // ...
      };
      
      this.setData({
        // 确保 membershipEndDate 有值
        membershipEndDate: formatDate(userInfo.membership_end_date),
        // ...
      }, () => {
        this.checkMembershipExpiry();
      });
    });
  }
}
```

**修复建议**：
```javascript
const formatDate = (dateStr) => {
  if (!dateStr) {
    console.warn('日期为空:', dateStr);
    return null; // 改为返回 null，而不是空字符串
  }
  const date = new Date(dateStr);
  const year = date.getFullYear();
  const month = (date.getMonth() + 1).toString().padStart(2, '0');
  const day = date.getDate().toString().padStart(2, '0');
  return `${year}-${month}-${day}`;
};
```

#### 问题3：检测函数没有被调用

**现象**：控制台没有任何 `========== 会员到期检测开始 ==========` 日志

**可能原因**：
1. `onShow` 的 `setData` 回调没有执行
2. `isLogin` 为 `false`
3. `userInfo` 不存在

**解决方案**：

**添加更多日志**：
```javascript
onShow: function () {
  console.log('onShow 执行，isLogin:', this.data.isLogin);
  
  if (this.data.isLogin) {
    this.loadUserData(() => {
      console.log('loadUserData 回调执行');
      
      if (this.data.userInfo) {
        const userInfo = this.data.userInfo;
        console.log('userInfo 存在，准备 setData');
        
        this.setData({
          // ...
        }, () => {
          console.log('setData 回调执行，准备检测会员到期状态');
          this.checkMembershipExpiry();
        });
      } else {
        console.warn('userInfo 不存在');
      }
    });
  }
}
```

## 💡 解决方案总结

### 最常见的3个问题

#### 1. 会员类型字段不是中文

**症状**：日志显示 `⚠️ 未识别的会员类型`

**解决**：
- 方案A：修改数据库，将 `membership_type` 改为"年卡"或"按次"
- 方案B：修改代码，兼容英文字段名

#### 2. 日期字段为空

**症状**：日志显示 `❌ 日期数据不完整，跳过检测`

**解决**：
- 检查数据库中 `membership_end_date` 字段是否有值
- 检查 `formatDate` 函数是否正确处理日期

#### 3. 检测函数未被调用

**症状**：控制台没有任何检测相关日志

**解决**：
- 检查 `isLogin` 是否为 `true`
- 检查 `loadUserData` 回调是否执行
- 检查 `setData` 回调是否执行
