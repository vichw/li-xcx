# 变量冲突问题修复说明

## 问题描述

在 `createRegistrationPayment` 云函数中，存在变量名冲突的问题：

1. 从数据库查询的入会费配置：`const config = configQuery.data[0];`
2. 从配置文件导入的微信支付配置：`const config = require('./config');`

这导致 `config` 变量被重复定义，引起错误。

## 问题原因

代码中使用了相同的变量名 `config` 来存储两个不同的配置对象：
- 数据库配置：包含入会费金额、次数等信息
- 微信支付配置：包含商户号、API密钥等信息

## 修复方案

### 1. 重命名微信支付配置变量

**修改前：**
```javascript
const config = require('./config');
```

**修改后：**
```javascript
const wxpayConfig = require('./config');
```

### 2. 恢复数据库配置变量

**修改前：**
```javascript
if (configQuery.data.length === 0) {
  return {
    success: false,
    message: '未找到入会费配置'
  };
}

const amount = config.value || 0.01;  // config 未定义
const allCount = config.allcount || 10;  // config 未定义
```

**修改后：**
```javascript
if (configQuery.data.length === 0) {
  return {
    success: false,
    message: '未找到入会费配置'
  };
}

const config = configQuery.data[0];  // 恢复这行代码
const amount = config.value || 0.01;
const allCount = config.allcount || 10;
```

### 3. 更新所有微信支付配置引用

**修改前：**
```javascript
subMchId: config.wxpay.mchId, // 商户号从配置获取
```

**修改后：**
```javascript
subMchId: wxpayConfig.wxpay.mchId, // 商户号从配置获取
```

## 变量说明

### config（数据库配置）
从 `configs` 表查询的入会费配置：
```javascript
{
  name: '入会费',
  type: 'member_price',
  value: 0.01,        // 缴费金额
  allcount: 10,       // 可用次数
  membership_days: 365 // 会员有效期天数
}
```

### wxpayConfig（微信支付配置）
从 `config.js` 文件导入的微信支付配置：
```javascript
{
  wxpay: {
    mchId: '1718016646',        // 商户号
    apiKey: '3fd7355fc79f443a24a47eb04f8cf4e6', // API密钥
    tradeType: 'JSAPI',
    vipAmount: 5000
  }
}
```
