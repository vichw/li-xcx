# 优化比赛结果显示 - 按子组过滤

## 📋 需求说明

用户在小程序中选择某个子组后，点击"比赛结果"tab，应该**只显示该子组的结果**，而不是显示所有子组的结果。

### 使用场景

1. **场景1：查看全部结果**
   - 用户在比赛详情页，没有选择特定子组
   - 点击"比赛结果"tab
   - 显示所有子组的结果（每个子组一个卡片）

2. **场景2：查看特定子组结果**
   - 用户选择了某个子组（如"高中组男子组-55kg级"）
   - 点击"比赛结果"tab
   - **只显示这个子组的结果**，不显示其他子组

## 🔍 问题分析

### 原有逻辑
无论是否选中子组，`loadResults` 方法都会获取所有子组的结果并显示，导致用户看到一长串列表，无法快速找到当前子组的结果。

### 期望逻辑
- **判断是否有选中的子组** (`this.data.selectedSubGroup`)
- **如果有** → 只获取该子组的结果
- **如果没有** → 获取所有子组的结果

## ✅ 解决方案

### 修改 `loadResults` 方法

```javascript
loadResults: function() {
  this.setData({ loading: true });
  
  // 判断是否选中了某个子组
  const selectedSubGroup = this.data.selectedSubGroup;
  
  // 【情况1】如果选中了子组，只获取该子组的结果
  if (selectedSubGroup && selectedSubGroup.sub_group_id) {
    wx.cloud.callFunction({
      name: 'competitionFunctions',
      data: {
        type: 'getResults',
        competition_id: this.data.competitionId,
        sub_group_id: selectedSubGroup.sub_group_id  // 传入子组ID
      },
      success: res => {
        if (res.result && res.result.success) {
          // 云函数返回扁平数组，包装成统一格式
          this.setData({
            results: [{
              sub_group_id: selectedSubGroup.sub_group_id,
              sub_group_name: selectedSubGroup.sub_group_name,
              results: res.result.data || []  // 扁平的学员结果数组
            }]
          });
        } else {
          wx.showToast({
            title: res.result?.message || '加载失败',
            icon: 'none'
          });
        }
        this.setData({ loading: false });
      },
      fail: err => {
        console.error('加载比赛结果失败:', err);
        wx.showToast({
          title: '加载失败',
          icon: 'none'
        });
        this.setData({ loading: false });
      }
    });
    return;
  }
  
  // 【情况2】没有选中子组，获取所有子组的结果
  Promise.all([
    // 获取所有子组（扁平列表）
    wx.cloud.callFunction({
      name: 'competitionFunctions',
      data: {
        type: 'getSubGroups',
        competition_id: this.data.competitionId,
        flat: true  // 获取扁平列表
      }
    }),
    // 获取所有结果数据
    wx.cloud.callFunction({
      name: 'competitionFunctions',
      data: {
        type: 'getResults',
        competition_id: this.data.competitionId
        // 不传 sub_group_id，获取所有结果
      }
    })
  ]).then(([subGroupsRes, resultsRes]) => {
    if (subGroupsRes.result?.success && resultsRes.result?.success) {
      const subGroups = subGroupsRes.result.data || [];
      const resultsData = resultsRes.result.data || [];
      
      // 创建结果映射（按 sub_group_id）
      const resultsMap = {};
      resultsData.forEach(group => {
        resultsMap[group.sub_group_id] = group.results || [];
      });
      
      // 合并子组和结果数据
      const mergedResults = subGroups.map(subGroup => ({
        sub_group_id: subGroup.sub_group_id,
        sub_group_name: subGroup.sub_group_name,
        results: resultsMap[subGroup.sub_group_id] || []
      }));
      
      this.setData({
        results: mergedResults
      });
    } else {
      wx.showToast({
        title: '加载失败',
        icon: 'none'
      });
    }
    this.setData({ loading: false });
  }).catch(err => {
    console.error('加载比赛结果失败:', err);
    wx.showToast({
      title: '加载失败',
      icon: 'none'
    });
    this.setData({ loading: false });
  });
},
```

## 🔑 关键逻辑

### 1. 判断是否选中子组

```javascript
const selectedSubGroup = this.data.selectedSubGroup;

if (selectedSubGroup && selectedSubGroup.sub_group_id) {
  // 只获取该子组的结果
} else {
  // 获取所有子组的结果
}
```

### 2. 云函数返回数据格式

**传入 `sub_group_id` 时（单个子组）**：
```javascript
{
  success: true,
  data: [  // 扁平的学员结果数组
    { student_name: "王伟", age: 15, rank: 1, ... },
    { student_name: "李明", age: 16, rank: 2, ... }
  ]
}
```

**不传 `sub_group_id` 时（所有子组）**：
```javascript
{
  success: true,
  data: [  // 分组的数据结构
    {
      sub_group_id: "high_school_male_w55",
      sub_group_name: "高中组男子组-55kg级",
      results: [
        { student_name: "王伟", ... },
        { student_name: "李明", ... }
      ]
    },
    // ... 其他子组
  ]
}
```

### 3. 前端数据格式统一

无论哪种情况，前端 `this.data.results` 的格式都是：
```javascript
[
  {
    sub_group_id: "xxx",
    sub_group_name: "xxx",
    results: [ /* 学员数组 */ ]
  },
  // ... 可能有多个子组（查看全部时）或只有一个（选中子组时）
]
```

这样前端模板可以统一处理，不需要修改。
