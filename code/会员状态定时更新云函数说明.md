# 会员状态定时更新云函数

## 📋 功能概述

定时云函数，每天自动刷新所有学员的会员状态字段，前端直接读取 `status` 字段显示，无需实时计算。

## 🎯 解决的问题

### 问题
- 前端每次显示状态都需要实时计算，增加逻辑复杂度
- 数据库中的 `status` 字段可能过时，与实际状态不符
- 多处使用会员状态，需要重复计算逻辑

### 解决方案
- 创建定时云函数，每天凌晨2点自动更新所有学员的 `status` 字段
- 前端直接读取数据库中的 `status` 字段，简化逻辑
- 统一状态计算逻辑，避免不一致

## 🔧 功能详细说明

### 1. 批量更新模式（默认）

**调用方式**：
```javascript
wx.cloud.callFunction({
  name: 'updateMembershipStatus',
  data: {
    type: 'batch'  // 或不传 type，默认为 batch
  }
})
```

**功能**：
- 遍历所有学员记录
- 根据会员类型、到期日期、剩余次数计算状态
- 批量更新 `status` 字段
- 记录更新时间 `status_update_time`

**返回结果**：
```javascript
{
  success: true,
  total: 500,              // 总记录数
  processedCount: 500,     // 已处理数
  updatedCount: 85,        // 实际更新数（状态变化的）
  errorCount: 0,           // 失败数
  errors: undefined,       // 错误详情（如有）
  message: "批量更新完成！处理 500 条，更新 85 条，失败 0 条"
}
```

### 2. 单个更新模式

**调用方式**：
```javascript
wx.cloud.callFunction({
  name: 'updateMembershipStatus',
  data: {
    type: 'single',
    studentId: 'student_id_xxx'
  }
})
```

**功能**：
- 更新指定学员的状态
- 适用于学员信息变更后立即更新状态

**返回结果**：
```javascript
{
  success: true,
  studentId: 'student_id_xxx',
  studentName: '张三',
  oldStatus: '正常',
  newStatus: '即将到期',
  message: "状态更新成功: 正常 → 即将到期"
}
```

## 📊 状态计算规则

### 年卡会员

| 剩余天数 | 状态 | 说明 |
|---------|------|------|
| < 0天 | 已过期 | 当前日期超过到期日期 |
| 0-7天 | 即将到期 | 7天内即将到期 |
| > 7天 | 正常 | 会员有效期充足 |
| 无到期日期 | 未设置 | 未设置到期日期 |

### 按次会员

| 剩余次数 | 状态 | 说明 |
|---------|------|------|
| = 0次 | 次数用完 | 课时次数已用完 |
| 1-5次 | 次数不足 | 课时次数不足，建议充值 |
| > 5次 | 正常 | 课时次数充足 |

## ⏰ 定时触发器配置

### Cron 表达式说明

**配置文件**: `config.json`

```json
{
  "triggers": [
    {
      "name": "dailyMembershipStatusUpdate",
      "type": "timer",
      "config": "0 0 2 * * * *"
    }
  ]
}
```

**Cron 格式**：`秒 分 时 日 月 星期 年`

**当前配置**：`0 0 2 * * * *`
- 每天凌晨 2:00:00 执行

**常用配置**：

| 时间 | Cron 表达式 | 说明 |
|------|------------|------|
| 每天凌晨0点 | `0 0 0 * * * *` | 零点执行 |
| 每天凌晨2点 | `0 0 2 * * * *` | 凌晨2点执行（推荐） |
| 每天凌晨3点 | `0 0 3 * * * *` | 凌晨3点执行 |
| 每天中午12点 | `0 0 12 * * * *` | 中午执行 |
| 每12小时 | `0 0 0,12 * * * *` | 0点和12点各执行一次 |
| 每6小时 | `0 0 0,6,12,18 * * * *` | 每6小时执行一次 |

## 📝 使用场景

### 场景1：定时自动更新（主要）

**时机**：每天凌晨2点自动执行

**流程**：
```

    ↓

    ↓

    ↓
```

## 💾 数据库字段说明

### 新增字段

云函数会自动添加以下字段到 `students` 集合：

```javascript
{
  _id: "student_id",
  name: "张三",
  // ...其他字段
  
  status: "即将到期",           // 会员状态（自动更新）
  status_update_time: Date     // 状态更新时间（自动记录）
}
```

### status 字段取值

- `"正常"` - 会员有效
- `"已过期"` - 会员已过期
- `"即将到期"` - 年卡7天内到期
- `"次数用完"` - 按次会员次数为0
- `"次数不足"` - 按次会员次数≤5
- `"未设置"` - 未设置会员信息
- `"未知"` - 无法判断

## 🐛 常见问题

### Q1: 云函数执行失败

**可能原因**：
- 云函数权限不足
- 数据库连接失败
- 数据格式异常

**解决方案**：
1. 检查云函数日志
2. 确认数据库权限配置
3. 验证数据格式是否正确

### Q2: 部分学员状态未更新

**可能原因**：
- 数据字段缺失（如 `membership_end_date`）
- 数据格式不正确
- 批处理中断

**解决方案**：
1. 查看错误日志
2. 检查具体学员数据
3. 手动调用单个更新模式

### Q3: 定时触发器未执行

**可能原因**：
- 触发器未正确配置
- 触发器被禁用
- Cron 表达式错误

**解决方案**：
1. 检查触发器配置
2. 验证 Cron 表达式
3. 在控制台查看触发器状态

### Q4: 执行时间过长

**可能原因**：
- 学员数据量过大
- 批处理大小过小
- 数据库查询慢

**解决方案**：
1. 增大 `batchSize`
2. 添加数据库索引
3. 优化查询条件
