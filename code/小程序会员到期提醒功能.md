# 小程序会员到期提醒功能

## 📋 功能概述

在小程序个人中心页面实现会员到期自动检测和弹窗提醒功能，帮助用户及时续费，减少流失。

## 🎯 实现需求

### 1. 年卡会员到期检测
- **已过期**：会员已过期，显示红色警告弹窗
- **即将到期**：7天内即将到期，显示橙色提醒弹窗

### 2. 按次会员次数检测
- **次数用完**：剩余次数为0，显示红色警告弹窗
- **次数不足**：剩余次数≤5次，显示橙色提醒弹窗

## ✅ 实现方案

### 技术方案

**前端实时检测方案**（已采用）

- 在个人中心页面 `onShow` 时触发检测
- 纯前端计算，无需后端接口
- 用户每次进入个人中心都会检测
- 提供立即续费入口

**优点**：
- 实现简单，无需后端改动
- 实时准确，数据来自当前用户信息
- 用户体验好，即时反馈

**缺点**：
- 只在用户进入个人中心时提醒
- 无法主动推送（如需主动推送需结合订阅消息）

## 🔧 实现详情

### 修改文件

**文件**: `code/miniprogram/pages/taekwondo/my/index.js`

### 1. 触发时机

在 `onShow` 生命周期函数中，加载完用户数据后触发检测：

```javascript
onShow: function () {
  if (this.data.isLogin) {
    this.loadUserData(() => {
      // ...其他加载逻辑
      
      this.setData({
        // ...设置会员数据
      }, () => {
        // 检查会员到期状态（在setData回调中执行）
        this.checkMembershipExpiry();
      });
    });
  }
}
```

**说明**：
- 在 `setData` 的回调中调用检测函数
- 确保会员数据已更新后再检测
- 每次进入个人中心页面都会检测

### 2. 主检测函数

```javascript
/**
 * 检查会员到期状态
 * - 年卡会员：检查是否已过期或7天内即将过期
 * - 按次会员：检查剩余次数是否用完或不足5次
 */
checkMembershipExpiry() {
  const { userInfo, membershipEndDate, remainingCount } = this.data;
  
  if (!userInfo) {
    return;
  }
  
  const membershipType = userInfo.membership_type;
  
  // 检查年卡会员到期情况
  if (membershipType === '年卡') {
    this.checkYearCardExpiry(userInfo, membershipEndDate);
  }
  // 检查按次会员剩余次数
  else if (membershipType === '按次') {
    this.checkCountCardExpiry(userInfo, remainingCount);
  }
}
```

**逻辑说明**：
1. 获取用户信息、会员类型、到期日期、剩余次数
2. 根据会员类型调用不同的检测函数
3. 年卡会员调用 `checkYearCardExpiry`
4. 按次会员调用 `checkCountCardExpiry`

### 3. 年卡会员检测

```javascript
/**
 * 检查年卡会员到期情况
 */
checkYearCardExpiry(userInfo, membershipEndDate) {
  if (!membershipEndDate || !userInfo.membership_end_date) {
    return;
  }
  
  const now = new Date();
  const endDate = new Date(userInfo.membership_end_date);
  
  // 计算剩余天数
  const timeDiff = endDate.getTime() - now.getTime();
  const daysRemaining = Math.ceil(timeDiff / (1000 * 60 * 60 * 24));
  
  // 已过期
  if (daysRemaining < 0) {
    wx.showModal({
      title: '会员已过期',
      content: `您的年卡会员已于 ${membershipEndDate} 到期\n\n为了不影响您的正常训练，请及时续费！`,
      confirmText: '立即续费',
      cancelText: '稍后再说',
      confirmColor: '#FF6B6B',
      success: (res) => {
        if (res.confirm) {
          this.goToRenewal();
        }
      }
    });
  }
  // 即将到期（7天内）
  else if (daysRemaining >= 0 && daysRemaining <= 7) {
    wx.showModal({
      title: '会员即将到期',
      content: `您的年卡会员还有 ${daysRemaining} 天到期\n到期时间：${membershipEndDate}\n\n续费可享优惠，请及时办理！`,
      confirmText: '立即续费',
      cancelText: '稍后再说',
      confirmColor: '#FFA500',
      success: (res) => {
        if (res.confirm) {
          this.goToRenewal();
        }
      }
    });
  }
}
```

**检测逻辑**：
1. 获取当前时间和会员到期时间
2. 计算剩余天数 `daysRemaining`
3. 根据剩余天数显示不同弹窗：
   - `< 0`：已过期（红色警告）
   - `0-7天`：即将到期（橙色提醒）
   - `> 7天`：不提醒

**弹窗内容**：
- **已过期**：显示到期日期，强调影响训练
- **即将到期**：显示剩余天数和到期日期，提示续费优惠

### 4. 按次会员检测

```javascript
/**
 * 检查按次会员剩余次数
 */
checkCountCardExpiry(userInfo, remainingCount) {
  const count = remainingCount || 0;
  
  // 次数已用完
  if (count === 0) {
    wx.showModal({
      title: '课时次数已用完',
      content: '您的课时次数已用完，无法继续消课\n\n请及时充值续费，继续您的跆拳道训练！',
      confirmText: '立即续费',
      cancelText: '稍后再说',
      confirmColor: '#FF6B6B',
      success: (res) => {
        if (res.confirm) {
          this.goToRenewal();
        }
      }
    });
  }
  // 次数不足5次
  else if (count > 0 && count <= 5) {
    wx.showModal({
      title: '课时次数不足',
      content: `您的课时次数仅剩 ${count} 次\n\n为避免影响训练，建议您提前充值续费！`,
      confirmText: '立即续费',
      cancelText: '稍后再说',
      confirmColor: '#FFA500',
      success: (res) => {
        if (res.confirm) {
          this.goToRenewal();
        }
      }
    });
  }
}
```

**检测逻辑**：
1. 获取剩余次数
2. 根据剩余次数显示不同弹窗：
   - `= 0`：次数用完（红色警告）
   - `1-5次`：次数不足（橙色提醒）
   - `> 5次`：不提醒

**弹窗内容**：
- **次数用完**：强调无法消课，提示立即续费
- **次数不足**：显示剩余次数，建议提前续费

## 📊 检测规则详解

### 年卡会员规则

| 状态 | 条件 | 弹窗标题 | 按钮颜色 | 说明 |
|------|------|---------|---------|------|
| 已过期 | 剩余天数 < 0 | 会员已过期 | 红色 `#FF6B6B` | 严重警告 |
| 即将到期 | 0 ≤ 剩余天数 ≤ 7 | 会员即将到期 | 橙色 `#FFA500` | 提前提醒 |
| 正常 | 剩余天数 > 7 | 不提醒 | - | 会员有效 |

**计算方式**：
```javascript
剩余天数 = Math.ceil((到期时间 - 当前时间) / (1000 * 60 * 60 * 24))
```

**示例**：
- 2025-01-20到期，今天2025-01-15 → 剩余5天 → 即将到期
- 2025-01-10到期，今天2025-01-15 → 剩余-5天 → 已过期
- 2025-02-20到期，今天2025-01-15 → 剩余36天 → 不提醒

### 按次会员规则

| 状态 | 条件 | 弹窗标题 | 按钮颜色 | 说明 |
|------|------|---------|---------|------|
| 次数用完 | 剩余次数 = 0 | 课时次数已用完 | 红色 `#FF6B6B` | 严重警告 |
| 次数不足 | 1 ≤ 剩余次数 ≤ 5 | 课时次数不足 | 橙色 `#FFA500` | 提前提醒 |
| 正常 | 剩余次数 > 5 | 不提醒 | - | 次数充足 |

**示例**：
- 剩余0次 → 次数用完 → 红色警告
- 剩余3次 → 次数不足 → 橙色提醒
- 剩余20次 → 不提醒

## 🚀 后续优化建议

### 1. 频率控制

**问题**：用户每次进入都会弹窗，可能造成骚扰

**解决方案**：
```javascript
// 记录上次提醒时间
const lastReminderTime = wx.getStorageSync('lastExpiryReminder') || 0;
const now = Date.now();
const oneDayMs = 24 * 60 * 60 * 1000;

// 如果今天已经提醒过，则不再提醒
if (now - lastReminderTime < oneDayMs) {
  return;
}

// 显示弹窗后保存时间
wx.setStorageSync('lastExpiryReminder', now);
```

**效果**：每天最多提醒1次

## ⚠️ 注意事项

### 1. 数据准确性

- 确保 `membership_end_date` 格式正确

- 用户信息不完整时不提醒

- 检测逻辑轻量，不影响页面加载
- 避免重复计算
- 异步操作不阻塞UI
