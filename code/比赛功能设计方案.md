# 比赛功能设计方案

## 一、功能概述

为跆拳道管理系统增加比赛管理功能，包括管理端的比赛维护、对战表生成、结果管理，以及小程序端的比赛查看功能。

## 二、数据库设计

### 2.1 competitions (比赛表)

```json
{
  "_id": "比赛ID",
  "name": "赛事名称",
  "start_date": "开始日期",
  "end_date": "结束日期",
  "grade": "级别(如:蓝红带三级)",
  "status": "状态(pending/ongoing/finished)",
  "top_display_count": 3,  // 展示前几名
  "participant_count": 16, // 参赛人数
  "bracket_generated": false, // 是否已生成对战表
  "create_time": "创建时间",
  "update_time": "更新时间"
}
```

**状态说明：**
- `pending`: 未开始（当前日期 < 开始日期）
- `ongoing`: 进行中（开始日期 <= 当前日期 <= 结束日期）
- `finished`: 已完成（当前日期 > 结束日期 或 管理员手动完成）

### 2.2 competition_brackets (对战表)

```json
{
  "_id": "对战ID",
  "competition_id": "比赛ID",
  "round": 1,  // 轮次: 1-第一轮, 2-第二轮, 3-半决赛, 4-决赛
  "match_no": 1, // 场次号
  "position": "A1", // 位置标识（用于淘汰赛树状图）
  "student1_id": "学员1ID",
  "student1_name": "学员1姓名",
  "student1_avatar": "学员1头像",
  "student2_id": "学员2ID", // 轮空时为null
  "student2_name": "学员2姓名",
  "student2_avatar": "学员2头像",
  "winner_id": "获胜者ID", // 未比赛时为null
  "winner_name": "获胜者姓名",
  "score": "3:2", // 比分
  "create_time": "创建时间"
}
```

### 2.3 competition_results (比赛结果表)

```json
{
  "_id": "结果ID",
  "competition_id": "比赛ID",
  "student_id": "学员ID",
  "student_name": "学员姓名",
  "student_avatar": "学员头像",
  "rank": 1, // 名次: 1-冠军, 2-亚军, 3-季军
  "create_time": "创建时间"
}
```

**功能按钮：**
- **新建比赛**: 打开比赛创建对话框
- **编辑**: 编辑比赛基本信息
- **生成对战表**: 根据同级别学员自动生成对战表
- **对战表管理**: 查看/编辑对战表和结果

#### 3.1.2 创建/编辑比赛对话框

**表单字段：**
- 赛事名称: 文本输入
- 开始日期: 日期选择器
- 结束日期: 日期选择器
- 级别: 下拉选择（从configs表获取belt_level）
- 展示前几名: 数字输入（默认3）

#### 3.1.3 生成对战表

**生成规则：**
1. 从students表筛选指定级别的学员
2. 过滤：isActive=true, status="正常"
3. 随机打乱学员顺序
4. 生成单败淘汰赛对战表
   - 如果人数是2的幂次（4,8,16,32），直接生成
   - 如果不是，部分选手首轮轮空
5. 对战表采用树状结构

**对战表示例（8人）：**
```
第一轮(4场)    半决赛(2场)    决赛(1场)
A vs B ──┐
          ├──→ 胜者1 ──┐
C vs D ──┘              │
                        ├──→ 冠军
E vs F ──┐              │
          ├──→ 胜者2 ──┘
G vs H ──┘
```

**重新生成：**
- 点击"重新生成"按钮，清空旧对战表，重新随机生成
- 已有比赛结果的不允许重新生成

## 四、技术实现

### 4.1 云函数

创建 `competitionFunctions` 云函数，包含以下方法：

1. **getCompetitions** - 获取比赛列表
   - 参数: status (可选), grade (可选)
   - 返回: 比赛列表

2. **createCompetition** - 创建比赛
   - 参数: name, start_date, end_date, grade, top_display_count
   - 返回: success, competition_id

3. **updateCompetition** - 更新比赛
   - 参数: competition_id, 更新字段
   - 返回: success

4. **deleteCompetition** - 删除比赛
   - 参数: competition_id
   - 返回: success

5. **generateBracket** - 生成对战表
   - 参数: competition_id
   - 逻辑: 
     - 查询指定级别的学员
     - 随机打乱
     - 生成淘汰赛对战表
   - 返回: success, brackets

6. **updateMatch** - 更新对战结果
   - 参数: match_id, score, winner_id
   - 返回: success

7. **saveResults** - 保存比赛结果
   - 参数: competition_id, results [{student_id, rank}]
   - 返回: success

8. **getCompetitionDetail** - 获取比赛详情
   - 参数: competition_id
   - 返回: 比赛信息 + 对战表 + 结果

## 六、对战表生成算法

### 6.1 单败淘汰赛算法

```javascript
function generateBracket(students) {
  const count = students.length;
  
  // 计算需要的轮次数
  const rounds = Math.ceil(Math.log2(count));
  const totalSlots = Math.pow(2, rounds); // 对战表总位置数
  
  // 如果人数不是2的幂次，需要安排轮空
  const byeCount = totalSlots - count;
  
  // 随机打乱学员顺序
  const shuffled = students.sort(() => Math.random() - 0.5);
  
  // 生成第一轮对战
  const brackets = [];
  let matchNo = 1;
  
  for (let i = 0; i < totalSlots; i += 2) {
    const student1 = shuffled[i] || null;
    const student2 = shuffled[i + 1] || null;
    
    brackets.push({
      round: 1,
      match_no: matchNo++,
      position: `R1-M${matchNo}`,
      student1_id: student1?._id,
      student1_name: student1?.name,
      student1_avatar: student1?.avatar,
      student2_id: student2?._id,
      student2_name: student2?.name,
      student2_avatar: student2?.avatar,
      winner_id: student2 ? null : student1?._id, // 轮空自动晋级
      winner_name: student2 ? null : student1?.name,
      score: student2 ? null : '轮空',
    });
  }
  
  // 生成后续轮次的空对战（等待前一轮结果）
  for (let round = 2; round <= rounds; round++) {
    const matchesInRound = Math.pow(2, rounds - round);
    for (let i = 0; i < matchesInRound; i++) {
      brackets.push({
        round: round,
        match_no: i + 1,
        position: `R${round}-M${i + 1}`,
        student1_id: null,
        student1_name: '待定',
        student2_id: null,
        student2_name: '待定',
        winner_id: null,
        score: null,
      });
    }
  }
  
  return brackets;
}
```

### 6.2 晋级规则

当管理员录入某场比赛的结果后：
1. 更新当前match的winner_id
2. 查找下一轮对应的match
3. 将winner填入下一轮对战表

## 七、UI设计建议

### 7.1 管理端
- 使用Element Plus的Table、Dialog、Form组件
- 状态标签使用不同颜色：
  - 未开始: 灰色
  - 进行中: 蓝色
  - 已完成: 绿色
- 对战表使用Tree或自定义树状图组件

### 7.2 小程序端
- 比赛卡片使用渐变背景，增加视觉吸引力
- 对战表使用简洁的列表展示（树状图在小屏幕不友好）
- 结果页面使用金银铜奖牌图标

## 八、注意事项

1. **数据完整性**
   - 删除比赛时，级联删除对战表和结果
   - 不允许删除已开始的比赛

2. **权限控制**
   - 管理端需要登录才能操作
   - 小程序端只读，无需登录即可查看

3. **性能优化**
   - 比赛列表分页加载
   - 对战表数据缓存

4. **边界处理**
   - 参赛人数过少（<2人）提示
   - 参赛人数过多（>64人）提示
   - 重复生成对战表确认提示

5. **扩展性**
   - 预留积分赛、循环赛等其他赛制的扩展空间
   - 预留比赛照片、视频等媒体资源字段
