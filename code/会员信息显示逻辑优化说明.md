# 会员信息显示逻辑优化说明

## 优化内容

### 1. 会员信息字段调整

**优化前**：
- 入馆日期：使用 `userInfo.joinDate`
- 会费到期：使用 `userInfo.expireDate`
- 会员状态：使用 `userInfo.status`

**优化后**：
- 入馆日期：使用 `membershipStartDate`（来自 `membership_start_date`）
- 会员到期：使用 `membershipEndDate`（来自 `membership_end_date`）
- 剩余次数：新增显示 `remainingCount`
- 会员状态：使用 `membershipStatus`（根据剩余次数和到期日期动态判断）

### 2. 会员状态判断逻辑

会员状态根据以下条件进行判断：

1. **正常**：会员未过期且剩余次数 > 0
2. **已过期**：会员已过期
3. **次数用完**：会员未过期但剩余次数 = 0
4. **未开通**：没有会员信息
5. **未知**：获取会员信息失败

#### JavaScript 逻辑优化

1. **日期格式化**：
   ```javascript
   const formatDate = (dateStr) => {
     if (!dateStr) return '';
     const date = new Date(dateStr);
     const year = date.getFullYear();
     const month = (date.getMonth() + 1).toString().padStart(2, '0');
     const day = date.getDate().toString().padStart(2, '0');
     return `${year}-${month}-${day}`;
   };
   ```

2. **会员状态加载**：
   ```javascript
   loadMembershipStatus: function() {
     const phoneNumber = this.data.phoneNumber;
     
     if (!phoneNumber) {
       return;
     }
     
     wx.cloud.callFunction({
       name: 'taekwondoFunctions',
       data: {
         type: 'checkMembershipStatus',
         phoneNumber: phoneNumber
       },
       success: res => {
         if (res.result && res.result.success) {
           const membershipInfo = res.result.data;
           
           this.setData({
             membershipStatus: membershipInfo.status,
             membershipMessage: membershipInfo.message,
             remainingCount: membershipInfo.remainingCount || 0,
             membershipStartDate: formatDate(membershipInfo.startDate),
             membershipEndDate: formatDate(membershipInfo.endDate)
           });
         } else {
           // 设置默认值
           this.setData({
             membershipStatus: '未开通',
             membershipMessage: '暂无会员信息',
             remainingCount: 0,
             membershipStartDate: '',
             membershipEndDate: ''
           });
         }
       },
       fail: err => {
         // 出错时设置默认值
         this.setData({
           membershipStatus: '未知',
           membershipMessage: '获取会员信息失败',
           remainingCount: 0,
           membershipStartDate: '',
           membershipEndDate: ''
         });
       }
     });
   }
   ```

### 4. 数据来源说明

#### 会员信息数据来源

1. **membership_start_date**：会员开始日期
   - 来源：`students` 表中的 `membership_start_date` 字段
   - 显示：入馆日期

2. **membership_end_date**：会员结束日期
   - 来源：`students` 表中的 `membership_end_date` 字段
   - 显示：会员到期

3. **remaining_count**：剩余次数
   - 来源：`students` 表中的 `remaining_count` 字段
   - 显示：剩余次数

4. **会员状态**：动态计算
   - 来源：根据 `remaining_count` 和 `membership_end_date` 计算
   - 显示：会员状态

### 5. 调用时机优化

会员状态信息在以下时机加载：

1. **页面显示时**：`onShow` 方法中调用
2. **登录成功后**：`doLogin` 成功回调中调用
3. **用户数据更新后**：确保会员状态信息同步更新

### 6. 错误处理

1. **网络错误**：显示"未知"状态
2. **无会员信息**：显示"未开通"状态
3. **数据异常**：设置默认值，避免页面显示错误

### 7. 样式说明

会员状态使用不同的样式：

- **正常状态**：`active-status` 类（绿色）
- **异常状态**：`inactive-status` 类（红色）

### 8. 部署说明

需要重新部署以下文件：

2. `pages/taekwondo/my/index.js` - 会员状态加载逻辑
