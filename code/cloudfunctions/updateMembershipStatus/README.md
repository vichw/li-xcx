# updateMembershipStatus 云函数

## 功能说明

定时更新所有学员的会员状态字段，支持批量更新和单个更新。

## 使用方法

### 批量更新（定时触发）

```javascript
// 自动执行：每天凌晨2点
// 或手动调用：
{
  "type": "batch"
}
```

### 单个更新

```javascript
{
  "type": "single",
  "studentId": "student_id_xxx"
}
```

## 状态规则

### 年卡会员
- `已过期`：剩余天数 < 0
- `即将到期`：剩余天数 0-7天
- `正常`：剩余天数 > 7天

### 按次会员
- `次数用完`：剩余次数 = 0
- `次数不足`：剩余次数 1-5次
- `正常`：剩余次数 > 5次

## 定时配置

- **执行时间**：每天凌晨 2:00:00
- **Cron 表达式**：`0 0 2 * * * *`
- **配置文件**：`config.json`

## 依赖

- `wx-server-sdk`: ~2.6.3
