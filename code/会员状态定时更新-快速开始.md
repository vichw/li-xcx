# 会员状态定时更新 - 快速开始指南

## 🚀 5分钟快速部署

### 步骤1：上传云函数（2分钟）

1. **打开微信开发者工具**

2. **找到云函数目录** `cloudfunctions`

3. **右键 → 新建 Node.js 云函数** → 输入名称 `updateMembershipStatus`

4. **复制文件到云函数目录**：
   - 复制 `code/cloudfunctions/updateMembershipStatus/index.js`
   - 复制 `code/cloudfunctions/updateMembershipStatus/package.json`
   - 复制 `code/cloudfunctions/updateMembershipStatus/config.json`

5. **右键云函数文件夹 → 上传并部署：云端安装依赖**

### 步骤2：测试云函数（1分钟）

在微信开发者工具的控制台中测试：

```javascript
wx.cloud.callFunction({
  name: 'updateMembershipStatus',
  data: {
    type: 'batch'
  },
  success: res => {
    console.log('✅ 测试成功:', res.result);
  },
  fail: err => {
    console.error('❌ 测试失败:', err);
  }
})
```

**预期结果**：
```javascript
{
  success: true,
  total: 10,
  processedCount: 10,
  updatedCount: 3,
  errorCount: 0,
  message: "批量更新完成！处理 10 条，更新 3 条，失败 0 条"
}
```

### 步骤3：验证定时触发器（2分钟）

1. **登录腾讯云控制台**
   - 地址：https://console.cloud.tencent.com/tcb

2. **进入：云开发 → 云函数 → updateMembershipStatus**

3. **点击"触发器"标签页**

4. **确认定时触发器存在**：
   - 名称：`dailyMembershipStatusUpdate`
   - 类型：定时触发
   - Cron：`0 0 2 * * * *`（每天凌晨2点）
   - 状态：✅ 已启用

5. **如果触发器不存在，手动创建**：
   - 点击"创建触发器"
   - 触发周期：自定义定时触发
   - Cron 表达式：`0 0 2 * * * *`
   - 点击"确定"

## ✅ 验证是否生效

### 方法1：查看学员状态

1. 在小程序中登录一个账号
2. 进入"我的"页面
3. 查看"会员状态"字段
4. 应该显示：正常、已过期、即将到期等

### 方法2：查看数据库

1. 打开云开发控制台 → 数据库 → students 集合
2. 查看任意学员记录
3. 确认有 `status` 字段和 `status_update_time` 字段

### 方法3：查看执行日志

1. 云函数控制台 → updateMembershipStatus → 日志
2. 查看是否有执行记录
3. 确认执行成功

## 🔧 常用操作

### 立即手动执行

```javascript
// 在小程序中任意位置调用
wx.cloud.callFunction({
  name: 'updateMembershipStatus',
  data: { type: 'batch' }
})
```

### 更新单个学员

```javascript
// 学员续费后立即更新状态
wx.cloud.callFunction({
  name: 'updateMembershipStatus',
  data: {
    type: 'single',
    studentId: 'student_id_xxx'
  }
})
```

### 修改执行时间

编辑 `config.json` 文件：

```json
{
  "triggers": [{
    "name": "dailyMembershipStatusUpdate",
    "type": "timer",
    "config": "0 0 3 * * * *"  // 改为凌晨3点
  }]
}
```

重新部署云函数。

## ⚠️ 注意事项

1. **首次部署后**，建议手动执行一次云函数，初始化所有学员状态

2. **定时更新有延迟**，最长可能24小时。重要操作后建议手动更新

3. **监控执行日志**，确保每天都正常执行

4. **数据库权限**，确保云函数有读写 students 集合的权限

## 🆘 常见问题

### Q: 云函数上传失败？

A: 检查网络连接，确认已登录云开发环境

### Q: 定时触发器没有创建？

A: 手动在控制台创建，或检查 config.json 格式

### Q: 状态没有更新？

A: 
1. 检查云函数执行日志
2. 手动调用测试
3. 检查数据库字段是否存在

### Q: 如何立即看到效果？

A: 在控制台或小程序中手动调用云函数
