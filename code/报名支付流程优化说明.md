# 报名支付流程优化说明

## 问题描述

用户已提交报名申请但未完成支付时，系统只显示"该手机号已经提交过报名申请"的提示，没有引导用户完成支付。

## 优化目标

当检测到用户已有报名申请但未支付时，应该直接弹出缴费弹窗，引导用户完成支付。

## 优化方案

### 1. 云函数逻辑优化

**修改前：**
```javascript
// 检查是否已有报名记录
const registrationQuery = await db.collection('registrations').where({
  phoneNumber: phoneNumber
}).count();

if (registrationQuery.total > 0) {
  return {
    success: false,
    message: '该手机号已经提交过报名申请',
    code: 'ALREADY_REGISTERED'
  };
}
```

**修改后：**
```javascript
// 检查是否已有报名记录
const registrationQuery = await db.collection('registrations').where({
  phoneNumber: phoneNumber
}).get();

if (registrationQuery.data.length > 0) {
  const registration = registrationQuery.data[0];
  
  // 检查报名记录的状态
  if (registration.status === '待缴费') {
    // 已提交报名但未支付，引导用户支付
    return {
      success: false,
      message: '您已提交报名申请，请完成缴费',
      code: 'NEED_PAYMENT'
    };
  } else if (registration.status === '已缴费') {
    // 已提交报名且已支付
    return {
      success: false,
      message: '该手机号已经提交过报名申请',
      code: 'ALREADY_REGISTERED'
    };
  } else {
    // 其他状态
    return {
      success: false,
      message: '该手机号已经提交过报名申请',
      code: 'ALREADY_REGISTERED'
    };
  }
}
```

### 2. 小程序页面逻辑优化

```javascript
switch (res.result.code) {
  case 'NEED_PAYMENT':
    // 已提交报名但未支付，直接显示缴费弹窗

    break;
  case 'ALREADY_REGISTERED':

    break;
  // ... 其他情况
}
```

## 业务流程优化

### 优化前的流程：
```
用户输入手机号 → 提交报名 → 检测到已有报名记录 → 显示"已提交过报名申请" → 用户困惑
```

### 优化后的流程：
```
用户输入手机号 → 提交报名 → 检测到已有报名记录 → 判断状态：
├─ 待缴费 → 直接弹出缴费弹窗 → 用户完成支付
├─ 已缴费 → 显示"已提交过报名申请" → 提示已报名
└─ 其他状态 → 显示相应提示信息
```

## 错误码说明

### 新增错误码：
- **`NEED_PAYMENT`**：已提交报名但未支付，需要引导用户支付
- **`ALREADY_REGISTERED`**：已提交报名且已支付，提示已报名

### 现有错误码：
- **`ALREADY_PAID`**：已是有效会员
- **`MEMBERSHIP_EXPIRED`**：会员已过期
- **`NO_REMAINING_COUNT`**：可用次数已用完
- **`MEMBERSHIP_NOT_ACTIVE`**：会员尚未生效
- **`MEMBERSHIP_SUSPENDED`**：会员已被暂停

## 用户体验改进
