# 修复比赛状态脚本

## 问题说明

当编辑比赛时，如果比赛日期是未来的，系统会自动将 status 设为 `pending`（未开始），导致小程序端无法显示该比赛。

## 解决方案

已修改云函数 `updateCompetition`，不再自动根据日期修改 status。

## 修复已有数据

如果已有比赛被设为 `pending` 状态，需要在云开发控制台手动修复：

### 方法1：在云开发控制台执行

1. 进入云开发控制台
2. 选择"数据库" → "competitions" 集合
3. 点击右上角的"高级操作"
4. 执行以下查询和更新：

```javascript
// 查询所有 pending 状态的比赛
db.collection('competitions')
  .where({
    status: 'pending'
  })
  .get()
  .then(res => {
    console.log('找到的 pending 比赛:', res.data);
  });

// 将所有 pending 状态改为 ongoing
db.collection('competitions')
  .where({
    status: 'pending'
  })
  .update({
    data: {
      status: 'ongoing'
    }
  })
  .then(res => {
    console.log('更新成功:', res);
  });
```

### 方法2：逐个修改

1. 进入云开发控制台
2. 选择"数据库" → "competitions" 集合
3. 找到 status 为 `pending` 的记录
4. 点击编辑，将 status 改为 `ongoing`
5. 保存

## 验证修复

修复后，在小程序端：
1. 进入"比赛"页面
2. 查看"进行中"tab
3. 应该能看到所有比赛了

## 未来避免

现在已修复云函数，以后：
- 创建比赛时，status 默认为 `ongoing`
- 编辑比赛时，status 不会自动改变
- 如需修改状态，管理员需要在管理端手动操作

## 状态说明

系统支持的比赛状态：
- `pending`: 未开始（目前不使用）
- `ongoing`: 进行中（默认状态）
- `finished`: 已完成（需要手动设置）

**建议**：所有比赛都保持 `ongoing` 状态，除非真正完成后手动改为 `finished`。
