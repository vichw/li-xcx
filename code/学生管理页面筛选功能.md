# 学生管理页面筛选功能

## 📋 修改内容

为学生管理页面增加多维度筛选功能，支持按会员类型和状态（包括即将到期）筛选学生。

## 🎯 新增功能

### 1. 会员类型筛选
- **按次会员**：只显示按次购买课时的学员
- **年卡会员**：只显示购买年卡的学员
- **全部**：显示所有学员（默认）

### 2. 状态筛选
- **正常**：会员有效期内且次数充足的学员
- **已过期**：会员已过期的学员
- **即将到期**：7天内即将到期的学员 ⚠️
- **次数用完**：按次会员次数已用完的学员
- **全部**：显示所有状态的学员（默认）

### 3. 筛选逻辑实现

**增强 `filteredStudents` 计算属性** (第484-512行):

```javascript
// 过滤后的学生列表
const filteredStudents = computed(() => {
  let result = students.value

  // 关键词搜索
  if (searchKeyword.value) {
    const keyword = searchKeyword.value.toLowerCase()
    result = result.filter(student =>
      student.name.toLowerCase().includes(keyword) ||
      student.phoneNumber.includes(keyword)
    )
  }

  // 会员类型筛选
  if (filterMembershipType.value) {
    result = result.filter(student =>
      student.membership_type === filterMembershipType.value
    )
  }

  // 状态筛选
  if (filterStatus.value) {
    result = result.filter(student => {
      const status = getStatus(student)
      return status === filterStatus.value
    })
  }

  return result
})
```

**筛选优先级**:
1. 关键词搜索
2. 会员类型筛选
3. 状态筛选
4. 多条件组合（AND逻辑）

### 4. 状态判断优化

**增强 `getStatus` 函数** (第893-930行):

```javascript
const getStatus = (row) => {
  // 根据会员日期和剩余次数计算状态
  const now = new Date()
  const start = row.membership_start_date ? new Date(row.membership_start_date) : null
  const end = row.membership_end_date ? new Date(row.membership_end_date) : null
  const remainingCount = row.remaining_count || 0
  
  // 计算距离到期的天数
  const daysUntilExpire = end ? Math.ceil((end.getTime() - now.getTime()) / (1000 * 60 * 60 * 24)) : null

  // 优先判断是否已过期
  if (end && now > end) {
    return '已过期'
  }
  
  // 判断是否未开始
  if (start && now < start) {
    return '未开始'
  }
  
  // 判断次数是否用完（按次会员）
  if (row.membership_type === '按次' && remainingCount <= 0) {
    return '次数用完'
  }
  
  // 判断是否即将到期（7天内）
  if (daysUntilExpire !== null && daysUntilExpire > 0 && daysUntilExpire <= 7) {
    return '即将到期'
  }
  
  return '正常'
}
```

**状态判断逻辑**:
1. **已过期** - 当前日期超过 `membership_end_date`
2. **未开始** - 当前日期早于 `membership_start_date`
3. **次数用完** - 按次会员且 `remaining_count <= 0`
4. **即将到期** - 距离到期日期 ≤ 7天且 > 0天
5. **正常** - 其他所有情况

## 📊 功能特性

### 1. 多条件组合筛选
支持同时使用多个筛选条件，例如：
- 搜索"张三" + 会员类型"按次" + 状态"即将到期"
- 会显示姓名包含"张三"的、按次会员中、即将到期的学员

### 2. 即将到期预警
- **判断规则**：距离到期日期 ≤ 7天
- **标签颜色**：橙色警告（`warning`）
- **适用对象**：所有会员类型（按次和年卡）

### 3. 清除筛选
- 每个筛选框都支持一键清除
- 清除后恢复显示所有符合其他条件的学员

### 4. 实时计算
- 状态根据当前日期实时计算
- 不依赖数据库中的状态字段
- 确保数据准确性

## 🎯 使用场景

### 场景1：查找即将到期的学员
**操作**：
1. 点击"状态筛选"下拉框
2. 选择"即将到期"
3. 系统显示所有7天内到期的学员

**用途**：提前联系学员续费

### 场景2：统计按次会员课时用完的学员
**操作**：
1. "会员类型"选择"按次"
2. "状态筛选"选择"次数用完"
3. 系统显示符合条件的学员

**用途**：提醒学员充值课时

### 场景3：查找特定学员并查看其状态
**操作**：
1. 在搜索框输入"张三"
2. "状态筛选"选择"正常"
3. 系统显示姓名包含"张三"且状态正常的学员

**用途**：快速定位并核实学员信息

### 场景4：查看所有已过期会员
**操作**：
1. "状态筛选"选择"已过期"
2. 系统显示所有过期学员

**用途**：整理过期会员名单，进行营销触达
