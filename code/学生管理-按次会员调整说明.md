# 学生管理 - 按次会员调整说明

## 📋 修改概述

对学生管理界面的按次会员功能进行了优化调整，提供更灵活的价格设置。

## 🎯 主要改进

### 1. 放开最低次数限制

**之前**：最低购买10次
**现在**：最低购买1次

- ✅ 支持更灵活的购买方案
- ✅ 满足少量试课需求
- ✅ 适应不同学员的购买能力

### 2. 单次价格可编辑

**新增功能**：单次课价格输入框

- ✅ 支持自定义单次课价格
- ✅ 默认使用系统配置的价格
- ✅ 精确到小数点后2位
- ✅ 范围：0 - 9999 元

### 3. 动态价格计算

**计算公式**：
```
会员价格（总价）= 购买次数 × 单次课价格
```

**特点**：
- ✅ 实时自动计算
- ✅ 价格透明可见
- ✅ 支持灵活定价

## 🔧 界面变化

### 添加学生 - 按次会员表单


### 编辑学生 - 历史数据兼容

**场景1：有 class_price 字段**
- 直接使用数据库中的 `class_price`

**场景2：无 class_price 字段（历史数据）**
- 如果有会员价格和购买次数，反推单次价格
  ```
  单次价格 = 会员价格 ÷ 购买次数
  ```
- 否则使用系统配置的默认价格

## 🔄 操作流程

### 新建学生（按次会员）

1. 选择"按次"会员类型
2. **编辑单次价格**（默认使用系统配置价格）
3. **输入购买次数**（最低1次）
4. 系统**自动计算**会员价格
5. 剩余次数自动等于购买次数

### 编辑学生（按次会员）

#### 情况1：调整单次价格

```
原价格: 150 元/次
新价格: 180 元/次

购买次数: 10 次（不变）

会员价格: 1500 元 → 1800 元（自动重算）
```

#### 情况2：增加购买次数

```
单次价格: 150 元/次（不变）

购买次数: 10 次 → 15 次

剩余次数: 8 次 → 13 次（自动计算：已消费2次，新增5次）
会员价格: 1500 元 → 2250 元（自动重算）
```

#### 情况3：同时调整价格和次数

```
单次价格: 150 元/次 → 180 元/次
购买次数: 10 次 → 15 次

剩余次数: 8 次 → 13 次（根据已消费次数计算）
会员价格: 1500 元 → 2700 元（180 × 15）
```

## 🔍 价格计算逻辑

### 新建学生

```javascript
// 1. 选择会员类型：按次
membershipType = '按次'

// 2. 设置单次价格（默认从系统配置读取）
classPrice = 150  // 可编辑

// 3. 输入购买次数
purchasedCount = 10

// 4. 自动计算总价
membershipPrice = classPrice × purchasedCount = 1500

// 5. 设置剩余次数
remainingCount = purchasedCount = 10
```

### 编辑学生 - 修改单次价格

```javascript
// 用户修改单次价格
classPrice = 150 → 180

// 自动重算总价
membershipPrice = 180 × 10 = 1800

// 剩余次数不变
remainingCount = 8（保持原值）
```

### 编辑学生 - 修改购买次数

```javascript
// 原始数据
originalPurchasedCount = 10
originalRemainingCount = 8
classPrice = 150

// 已消费次数
consumedCount = 10 - 8 = 2

// 用户修改购买次数
purchasedCount = 10 → 15

// 自动计算新的剩余次数
remainingCount = 15 - 2 = 13

// 自动重算总价
membershipPrice = 150 × 15 = 2250
```

## ⚠️ 注意事项

### 1. 历史数据兼容

- 旧数据无 `class_price` 字段
- 编辑时自动反推：`class_price = membership_price ÷ purchased_count`
- 保存后会添加 `class_price` 字段

### 2. 价格精度

- 单次价格支持小数点后2位
- 总价自动四舍五入到小数点后2位

### 3. 剩余次数计算

- **新建**：剩余次数 = 购买次数
- **编辑**：剩余次数 = 新购买次数 - 已消费次数
- 确保剩余次数 ≥ 0

### 4. 年卡会员

- 年卡会员不显示单次价格
- 年卡会员不显示购买次数
- 价格由等级对应的年卡配置决定

## 🐛 常见问题

### Q1: 历史学员没有单次价格怎么办？

**A**: 系统会自动处理：
1. 如果有会员价格和购买次数，自动反推单次价格
2. 否则使用系统配置的默认价格
3. 编辑保存后会添加 `class_price` 字段

### Q2: 修改单次价格后，剩余次数会变吗？

**A**: 不会。修改单次价格只影响总价，不影响剩余次数。

### Q3: 修改购买次数后，已上的课会丢失吗？

**A**: 不会。系统会根据已消费次数自动计算新的剩余次数。

示例：
```
原购买: 10次，已上2次，剩余8次
新购买: 15次
结果: 已上仍是2次，剩余变为13次（15-2）
```

### Q4: 可以设置0元的单次价格吗？

**A**: 可以。适用于免费体验课或赠送课时的场景。

### Q5: 购买次数可以改成0吗？

**A**: 不可以。按次会员最低购买1次。如果不需要按次，请选择"年卡"会员类型。
