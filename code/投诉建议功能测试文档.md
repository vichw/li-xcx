# 投诉建议功能测试文档

## 📝 功能概述

本功能模块允许用户在小程序端提交投诉和建议，并在管理端进行处理和回复。核心特性包括：

- ✅ 支持上传最多5张图片
- ✅ 投诉类别动态加载（从configs表读取）
- ✅ 提交人信息自动获取
- ✅ 必须登录后才能访问
- ✅ 4种状态流转（待处理→处理中→已解决/已关闭）
- ✅ 红点显示未读回复数

---

## 🗂️ 数据准备

### 1. 云函数部署

确保以下云函数已部署：

```bash
# 投诉建议云函数
code/cloudfunctions/feedbackFunctions/
```

**部署步骤**：
1. 在微信开发者工具中，右键点击 `feedbackFunctions` 目录
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成

### 2. 配置数据初始化

在云数据库 `configs` 集合中添加投诉类别配置：

```json
{"type":"complain","name":"教学质量","value":"teaching_quality"}
{"type":"complain","name":"场馆设施","value":"venue_facilities"}
{"type":"complain","name":"服务管理","value":"service_management"}
{"type":"complain","name":"考级比赛","value":"exam_competition"}
{"type":"complain","name":"收费相关","value":"fee_related"}
{"type":"complain","name":"其他","value":"other"}
```

**导入方法**：
- 方法1：使用管理端数据导入功能
- 方法2：在云开发控制台直接导入 `manager/complain-config.json`

### 3. 数据库集合

系统会自动创建 `feedback` 集合，无需手动创建。
