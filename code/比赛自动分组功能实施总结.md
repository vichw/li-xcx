# 比赛自动分组功能实施总结

## 📋 变更概述

本次更新将比赛功能从**手动选拔模式**升级为**自动分组模式**，支持按年龄、性别、体重三级分组，每个子组独立生成对战表和排名结果。

**更新时间**：2025-12-17  
**状态**：✅ 云函数和小程序端已完成，管理端待实施

---

## 🎯 核心变化

### 原流程
```
报名 → 手动选拔 → 生成单一对战表 → 结果展示
```

### 新流程
```
报名 → 自动分组 → 生成多个子组对战表 → 按子组展示结果
```

### 分组层级
```
比赛
├── 年龄组（高中/初中/小学甲乙丙/幼儿）
    ├── 性别组（高中/初中分男女，小学/幼儿不分）
        └── 体重级别（-45kg、-48kg、-51kg...+78kg）
```

## 🚀 使用流程

### 管理员操作流程

1. **创建分组规则**（首次使用）
   - 进入"分组规则配置"页面
   - 使用默认配置或创建自定义规则
   - 保存配置

2. **创建比赛**
   - 填写比赛基本信息
   - ✅ 开启"启用自动分组"
   - 选择分组规则
   - 保存比赛

3. **等待学员报名**
   - 学员在小程序端报名
   - 系统自动分配到对应子组

4. **查看分组情况**
   - 进入"分组管理"页面
   - 查看各子组人数统计

5. **生成对战表**
   - 点击"一键生成所有对战表"
   - 或为单个子组生成

6. **录入比赛结果**
   - 选择子组
   - 录入对战结果
   - 保存排名

### 学员操作流程

1. **报名比赛**
   - 填写姓名、身份证、体重等信息
   - 提交报名
   - ✅ 查看自动分配的组别

2. **查看比赛详情**
   - 进入比赛详情页
   - ✅ 查看"分组情况"Tab
   - 点击自己所在的子组
   - 查看对战表和结果

## 🔄 兼容性说明

### 双模式支持

系统同时支持两种模式：

1. **传统模式**（`enable_auto_grouping = false`）
   - 手动设置年龄和体重范围
   - 手动选拔参赛者
   - 生成单一对战表
   - 不分组，统一排名

2. **自动分组模式**（`enable_auto_grouping = true`）
   - 关联分组规则配置
   - 自动分组
   - 生成多个子组对战表
   - 按子组独立排名

### 数据迁移

**现有比赛数据无需迁移**，默认为传统模式，系统自动兼容。

新建比赛时可选择启用自动分组。

## ⚠️ 注意事项

### 1. 分组规则设计

- 年龄组范围不能重叠
- 体重级别必须连续覆盖（最后一个使用 `max: 999`）
- 体重单位统一为kg

### 2. 子组标识

- `sub_group_id` 格式：`{age_group_code}_{gender_group}_{weight_category_code}`
- 例如：`high_school_male_w48`
- 全局唯一，用于关联对战表和结果

### 3. 性能考虑

- 单个比赛子组数量建议不超过50个
- 每个子组参赛人数2-64人
- 生成对战表采用批量插入（每批20条）

### 4. 用户体验

- 报名成功后立即显示分组信息
- 小程序端直观展示分组结构
- 支持面包屑导航返回
