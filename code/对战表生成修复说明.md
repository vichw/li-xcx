# 对战表生成修复说明

## 🐛 问题描述

当参赛人数为奇数（如3人）时，生成的对战表存在以下问题：
1. 第一轮有轮空，但轮空获胜的选手没有自动晋级到下一轮
2. 决赛显示两个"待定"，且都标记为获胜者
3. 对战表逻辑混乱

## ✅ 修复内容

### 修复前的逻辑
```javascript
// 后续轮次全部设为"待定"
for (let round = 2; round <= rounds; round++) {
  // ...
  student1_name: '待定',  // ❌ 没有考虑轮空晋级
  student2_name: '待定',  // ❌ 没有考虑轮空晋级
}
```

### 修复后的逻辑
```javascript
// 自动填充轮空晋级的选手
for (let round = 2; round <= rounds; round++) {
  // 查找上一轮的获胜者
  const prevMatch1 = brackets[prevRoundStartIndex + prevMatch1Index];
  const prevMatch2 = brackets[prevRoundStartIndex + prevMatch2Index];
  
  // 如果上一轮有获胜者（包括轮空），自动晋级
  const student1 = prevMatch1 && prevMatch1.winner_id ? {
    _id: prevMatch1.winner_id,
    name: prevMatch1.winner_name
  } : null;
  
  const student2 = prevMatch2 && prevMatch2.winner_id ? {
    _id: prevMatch2.winner_id,
    name: prevMatch2.winner_name
  } : null;
}
```

## 🎯 关键验证点

1. **轮空处理**
   - ✅ 轮空对战应该显示"XX VS 轮空"
   - ✅ 轮空对战应该自动标记获胜者
   - ✅ 获胜者姓名应该正确显示
   - ✅ 比分应该显示"轮空"

2. **自动晋级**
   - ✅ 轮空获胜的选手应该自动出现在下一轮
   - ✅ 下一轮不应该显示"待定 VS 待定"（如果有轮空晋级）
   - ✅ 晋级的选手姓名应该正确显示

3. **决赛显示**
   - ✅ 决赛不应该出现两个都是"待定"且都标记为获胜者的情况
   - ✅ 如果有轮空晋级，决赛应该显示"待定 VS 晋级者姓名"
