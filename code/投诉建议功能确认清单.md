## 🔌 云函数接口清单

### feedbackFunctions 云函数

#### 1. submitFeedback - 提交投诉/建议
```javascript
参数: {
  type: 'complaint' | 'suggestion',
  category: string,
  title: string,
  content: string,
  images: string[],  // 云存储文件ID数组
  user_phone: string
}
返回: {
  success: boolean,
  feedback_id: string,
  message: string
}
```

#### 2. getMyFeedbacks - 获取我的投诉列表
```javascript
参数: {
  status?: 'pending' | 'processing' | 'resolved' | 'closed',
  limit: 20,
  skip: 0
}
返回: {
  success: boolean,
  data: Feedback[],
  total: number
}
```

#### 3. getFeedbackDetail - 获取详情
```javascript
参数: {
  feedback_id: string
}
返回: {
  success: boolean,
  data: Feedback
}
```

#### 4. getAllFeedbacks - 获取所有投诉（管理端）
```javascript
参数: {
  type?: 'complaint' | 'suggestion',
  category?: string,
  status?: string,
  start_date?: string,
  end_date?: string,
  keyword?: string,
  limit: 20,
  skip: 0
}
返回: {
  success: boolean,
  data: Feedback[],
  total: number,
  statistics: {
    pending: number,
    todayNew: number,
    total: number
  }
}
```

#### 5. handleFeedback - 处理投诉（管理端）
```javascript
参数: {
  feedback_id: string,
  status: 'processing' | 'resolved' | 'closed',
  admin_reply: string,
  admin_name: string
}
返回: {
  success: boolean,
  message: string
}
```

## 🎨 图片上传功能

### 小程序端
- 使用 `wx.chooseImage` 选择图片（最多3张）
- 使用 `wx.cloud.uploadFile` 上传到云存储
- 返回云存储文件ID（`cloud://xxx.png`）
- 提交时将文件ID数组传给云函数

### 管理端
- 显示图片列表（使用云存储URL）
- 点击图片可查看大图
- 使用 Element Plus 的 `el-image` 组件

### 云存储
- 存储路径：`feedback-images/{feedback_id}/{timestamp}.png`
- 权限设置：所有用户可读

## 📸 图片功能详细说明

### 小程序端 - 图片上传

**选择图片**:
```javascript
wx.chooseImage({
  count: 3,  // 最多3张
  sizeType: ['compressed'],  // 压缩图
  sourceType: ['album', 'camera']  // 相册或拍照
})
```

**上传流程**:
```
用户选择图片
    ↓
显示预览（可删除）
    ↓
点击提交时上传到云存储
    ↓
获取云存储URL
    ↓
提交到云函数
```

**云存储路径**:
```
feedback-images/
  └─ {openid}/
      └─ {timestamp}_{index}.jpg
```

### 管理端 - 图片展示

**列表页**: 
- 如果有图片，显示📷图标

**详情页**:
```vue
<el-image
  v-for="img in feedback.images"
  :src="img"
  :preview-src-list="feedback.images"
  fit="cover"
/>
```

## 🎯 用户体验设计

### 小程序端体验

**提交流程**（简化）:
```
1. 点击"我的" → "投诉建议"
2. 点击右上角"+"
3. 选择类型（投诉/建议）
4. 选择类别（下拉列表）
5. 输入标题
6. 输入描述
7. 上传图片（可选，但建议上传以便说明问题）
8. 输入联系方式
9. 点击"提交"
10. 提交成功 → 返回列表
```

**查看进度**:
```
1. 进入"投诉建议"列表
2. 看到状态标签：
   - 待处理（灰色）
   - 处理中（橙色）
   - 已解决（绿色）
3. 点击查看详情
4. 看到管理员回复
```

### 管理端体验

**处理流程**:
```
1. 打开"投诉建议"菜单
2. 看到待处理数量：5条 🔴
3. 筛选或点击某条
4. 点击"处理"
5. 查看详情和图片
6. 填写回复
7. 更新状态
8. 保存
9. 用户在小程序看到回复
```

## ⚠️ 注意事项

### 1. 图片存储
- 使用腾讯云存储（CloudBase Storage）
- 需要配置存储权限
- 建议设置图片大小限制（单张<5MB）

### 2. 隐私保护
- 联系方式在管理端完整显示
- 如果后续支持匿名，用户信息需脱敏

### 3. 数据安全
- 投诉内容可能包含敏感信息
- 建议设置管理员权限（只有管理员可查看）
