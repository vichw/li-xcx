# 首次登录考级信息加载问题修复说明

## 问题描述

小程序首次登录时考级信息为空，但切换tab页签后信息能正常加载。

## 问题分析

### 问题根源

这是一个典型的**异步时序问题**。在 `checkLoginStatus` 和 `doLogin` 方法中：

1. 调用 `setData` 设置 `userInfo` 等数据（异步操作）
2. 紧接着调用 `loadGradeInfo()` 加载考级信息
3. 由于 `setData` 是异步的，在 `loadGradeInfo` 执行时，`this.data.userInfo` 可能还是 `null`
4. `loadGradeInfo` 方法中有判断：如果 `!this.data.userInfo`，则直接返回

```javascript
loadGradeInfo: function() {
  const that = this;
  if (!that.data.userInfo) {
    console.log('用户信息未加载完成，跳过加载考级信息');
    return;  // 直接返回，不加载考级信息
  }
  // ... 后续代码 ...
}
```

### 为什么切换tab后能正常加载

当切换tab页签时，触发 `onShow` 方法，此时 `userInfo` 已经设置完成，所以考级信息能正常加载。

## 修复方案

在 `setData` 的**回调函数**中调用数据加载方法，确保 `userInfo` 已经设置完成后再加载考级信息。

## 修改文件

`miniprogram/pages/taekwondo/my/index.js`

## 修改内容

### 1. 修复 `checkLoginStatus` 方法（第80-123行）

**修改后：**
```javascript

  userInfo: userInfo,
  phoneNumber: userInfo.phoneNumber || '',
  membershipStatus: userInfo.status || '',

```

## 修改要点

1. **使用 setData 回调函数**：将所有依赖 `userInfo` 的数据加载方法放在 `setData` 的回调函数中
2. **合并 setData 调用**：在 `doLogin` 方法中，将两次 `setData` 合并为一次，减少渲染次数，提高性能
3. **补充遗漏的方法调用**：在 `doLogin` 方法中补充了 `loadGradeInfo()` 和 `loadGradeExamPayStatus()` 的调用

## 预期效果

1. **首次登录时**，考级信息能正常加载显示
2. **切换tab页签时**，考级信息仍然能正常加载（保持原有功能）
3. **性能优化**：减少了不必要的 `setData` 调用次数

## 技术要点

### 小程序 setData 的异步特性

小程序的 `setData` 是异步操作，有以下特点：

1. **异步更新**：调用 `setData` 后，数据不会立即更新到 `this.data` 中
2. **回调函数**：可以在 `setData` 的第二个参数传入回调函数，在数据更新完成后执行
3. **最佳实践**：所有依赖 `setData` 更新数据的操作，都应该在回调函数中执行

### 正确写法

```javascript
this.setData({
  key: value
}, () => {
  // 数据更新完成后的回调
  // 可以安全地使用 this.data.key
});
```

### 错误写法

```javascript
this.setData({
  key: value
});
// 立即使用 this.data.key（可能还未更新）
this.useKeyData();
```
