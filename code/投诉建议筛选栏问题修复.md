# 投诉建议筛选栏问题修复

## 🐛 问题描述

### 问题1：展开/收起按钮被遮挡
- **现象**：展开/收起链接在页面右侧被裁切，显示不完整
- **原因**：操作按钮区域的列宽（span=4）太窄，无法容纳3个操作项

### 问题2：类别下拉框无数据
- **现象**：点击类别下拉框，显示"无数据"
- **原因**：`getConfigs()` 函数未传递参数，默认获取 `belt_level` 类型，而不是 `complain` 类型

### 修复2：修复类别数据加载


- ✅ 传入 `'complain'` 参数，直接获取投诉类别数据

## 🔍 问题根源分析

### 问题1根源：列宽计算不合理

#### Element Plus 栅格系统说明：
- 总宽度：24列
- 每列宽度：100% / 24 ≈ 4.17%

#### 原列宽分配：
| 列 | span | 实际宽度 | 内容 |
|----|------|---------|------|
| 1  | 6    | 25%     | 类型下拉框 |
| 2  | 6    | 25%     | 状态下拉框 |
| 3  | 8    | 33.3%   | 搜索输入框 |
| 4  | 4    | 16.7%   | **3个按钮+链接** ❌ |

**问题**：16.7% 的宽度需要容纳：
- 查询按钮（约80px）
- 重置按钮（约80px）
- 展开链接（约60px）
- 间距（30px）
- **总计约250px，但16.7%在1920px宽度下只有320px**

在较小屏幕或浏览器窗口下，展开链接容易被遮挡。

#### 优化后的列宽：
| 列 | span | 实际宽度 | 内容 |
|----|------|---------|------|
| 1  | 5    | 20.8%   | 类型下拉框 ✅ |
| 2  | 5    | 20.8%   | 状态下拉框 ✅ |
| 3  | 8    | 33.3%   | 搜索输入框 ✅ |
| 4  | 6    | 25%     | **3个按钮+链接** ✅ |

**改进**：25% 的宽度在1920px下约480px，足够容纳所有操作项。

### 问题2根源：API调用参数错误

#### cloudbase.js 中的 getConfigs 函数定义：
```javascript
export const getConfigs = async (type = 'belt_level') => {
  return await getConfig(type);
}

export const getConfig = async (type = 'belt_level') => {
  const database = await ensureDatabase();
  if (!database) return [];
  
  try {
    let query = database.collection('configs');
    if (Array.isArray(type)) {
      query = query.where({ type: database.command.in(type) });
    } else if (typeof type === 'string') {
      query = query.where({ type });  // ← 根据 type 过滤
    }
    const { data } = await query.get();
    return data;
  } catch (error) {
    handleDatabaseError(error);
    return [];
  }
}
```

#### 调用流程：
1. `loadCategories()` 调用 `getConfigs()`
2. 未传参数，默认 `type = 'belt_level'`
3. 查询条件：`{ type: 'belt_level' }`
4. 返回结果：只包含腰带级别数据，不包含投诉类别

#### 数据库中的数据：
```javascript
// configs 集合
[
  { type: 'belt_level', name: '白带十级', ... },
  { type: 'belt_level', name: '黄带八级', ... },
  { type: 'complain', name: '教学质量', value: 'teaching_quality' },
  { type: 'complain', name: '场馆设施', value: 'venue_facilities' },
  // ...
]
```

#### 修复方案：
传入正确的参数 `getConfigs('complain')`，直接获取投诉类别数据。
