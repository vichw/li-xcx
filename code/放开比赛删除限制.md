# 放开比赛删除限制

## 📋 修改内容

修改比赛管理页面，允许删除任何状态的比赛（包括进行中和已完成的比赛），以满足测试场景下清理数据的需求。

## 🎯 修改原因

- **测试需求**：测试环境可能需要删除已创建的比赛数据
- **数据清理**：管理员可能需要删除错误创建或过期的比赛
- **灵活性提升**：不再限制只能删除"未开始"的比赛

## 💻 代码片段

### 删除函数完整代码

```javascript
// 删除比赛
const deleteCompetition = async (row) => {
  try {
    // 根据比赛状态提供不同的警告信息
    let warningMessage = `确定要删除"${row.name}"吗？`;
    
    if (row.status === 'ongoing') {
      warningMessage += `\n\n⚠️ 该比赛正在进行中！`;
    } else if (row.status === 'finished') {
      warningMessage += `\n\n⚠️ 该比赛已完成！`;
    }
    
    if (row.registration_count > 0 || row.participant_count > 0) {
      warningMessage += `\n• 将删除 ${row.registration_count || 0} 条报名记录`;
    }
    
    if (row.bracket_generated) {
      warningMessage += `\n• 将删除所有对战表和比赛结果`;
    }
    
    warningMessage += `\n\n此操作不可恢复，请谨慎操作！`;
    
    await ElMessageBox.confirm(
      warningMessage,
      '确认删除',
      {
        confirmButtonText: '确定删除',
        cancelButtonText: '取消',
        type: 'error',
        dangerouslyUseHTMLString: false
      }
    );
    
    loading.value = true;
    const result = await callFunction('competitionFunctions', {
      type: 'deleteCompetition',
      competition_id: row._id
    });
    
    if (result.success) {
      ElMessage.success('删除成功');
      loadCompetitions();
    } else {
      ElMessage.error(result.message || '删除失败');
    }
  } catch (error) {
    if (error !== 'cancel') {
      console.error('删除比赛失败:', error);
      ElMessage.error('删除失败');
    }
  } finally {
    loading.value = false;
  }
};
```

## 🎯 使用场景

### 场景1：测试环境清理
**操作**：管理员需要清理测试数据
**流程**：
1. 进入比赛管理页面
2. 找到需要删除的测试比赛
3. 点击"删除"按钮
4. 查看警告信息，确认删除
5. 系统删除比赛及所有关联数据

### 场景2：删除错误创建的比赛
**操作**：比赛已开始但发现配置错误
**流程**：
1. 点击"删除"按钮
2. 系统显示警告：⚠️ 该比赛正在进行中！
3. 确认删除
4. 重新创建正确配置的比赛

### 场景3：清理历史数据
**操作**：清理已完成的过期比赛
**流程**：
1. 筛选"已完成"状态的比赛
2. 选择需要删除的比赛
3. 点击"删除"按钮
4. 确认删除对战表和结果
5. 释放数据库空间

## ⚠️ 注意事项

### 1. 数据不可恢复
- 删除操作是永久性的
- 所有关联数据（报名、对战表、结果）都会被删除
- 请确保在删除前做好数据备份

### 2. 生产环境谨慎使用
- 建议仅在测试环境使用删除功能
- 生产环境删除前务必确认
- 可以考虑改为"归档"功能而非直接删除

### 3. 权限控制建议
- 建议为删除功能添加额外的权限验证
- 可以限制只有超级管理员才能删除进行中/已完成的比赛
- 考虑增加操作日志记录

### 4. 数据关联检查
云函数 `deleteCompetition` 应确保删除以下关联数据：
- `competition_registrations` - 报名记录
- `competition_brackets` - 对战表
- `competition_results` - 比赛结果
- `competition_sub_groups` - 子组信息
