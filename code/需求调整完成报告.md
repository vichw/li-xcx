### 2. 报名页面增加资格校验和子组显示 ✅

**需求**：报名时需要根据该比赛选定的规则校验学生是否匹配，如果匹配则显示子组，否则提示详细错误

**实现功能**：
1. 新增云函数方法 `validateParticipantEligibility` 用于校验参赛资格
2. 报名前调用校验接口
3. 校验成功：显示将要分配的子组信息并确认报名
4. 校验失败：显示详细的错误原因（年龄不符/体重不符）

**修改文件**：
- `code/cloudfunctions/competitionFunctions/index.js` - 新增校验方法
- `code/miniprogram/pages/taekwondo/competition-register/index.js` - 修改报名流程

**用户体验流程**：
```
填写报名信息 → 点击提交
  ↓
调用资格校验接口
  ↓
┌─────────────┴──────────────┐
↓                            ↓
✅ 符合条件                  ❌ 不符合条件
显示分配子组信息              显示详细错误原因
"您将被分配到：               "抱歉，您不符合参赛要求
 高中男子组-48kg级"            年龄15岁不在任何分组范围内"
[确认报名]                    [我知道了]
  ↓
提交报名
  ↓
显示报名成功和分组信息
```

**关键代码**：
```javascript
// 新增校验方法
async function validateParticipantEligibility(event) {
  const { competition_id, age, gender, weight } = event;
  
  try {
    const groupInfo = calculateGroup(age, gender, weight, ageGroups);
    return {
      success: true,
      eligible: true,
      sub_group_info: groupInfo
    };
  } catch (error) {
    return {
      success: true,
      eligible: false,
      error_reason: error.message  // 详细错误原因
    };
  }
}

// 报名页面调用校验
validateEligibility: function() {
  wx.cloud.callFunction({
    name: 'competitionFunctions',
    data: {
      type: 'validateParticipantEligibility',
      competition_id: this.data.competitionId,
      age: parseInt(age),
      gender: gender,
      weight: parseFloat(weight)
    },
    success: res => {
      if (res.result.eligible) {
        // 显示子组信息并确认报名
        wx.showModal({
          title: '资格校验通过',
          content: `您将被分配到：\n${subGroupInfo.sub_group_name}...`
        });
      } else {
        // 显示详细错误
        wx.showModal({
          title: '不符合参赛条件',
          content: res.result.error_reason
        });
      }
    }
  });
}
```

## 📝 使用说明更新

### 管理员操作流程

**创建比赛**：
1. 进入"比赛管理" → "新建比赛"
2. 填写比赛基本信息
3. **必须选择分组规则**（从下拉列表选择）
4. 保存比赛

**管理比赛**：
1. 点击"分组管理"查看所有子组
2. 等待学员报名
3. 查看各子组的报名人数
4. 点击"一键生成所有对战表"

### 学员操作流程

**报名比赛**：
1. 进入比赛详情 → "立即报名"
2. 填写姓名、身份证、体重、联系方式
3. 点击提交
4. **查看资格校验结果**：
   - 符合：显示将要分配的子组，确认报名
   - 不符合：显示详细错误原因
5. 确认后完成报名
6. 查看报名成功信息（包含分组详情）

**查看比赛**：
1. 进入比赛详情
2. 默认显示"分组情况"
3. 点击子组查看该子组的对战表和结果

## ⚠️ 注意事项

### 1. 必须配置分组规则

- 创建比赛前，确保已有可用的分组规则
- 可以使用默认的"标准跆拳道分组规则"
- 或自定义创建新的分组规则

### 2. 报名前告知学员

建议在比赛详情或报名说明中告知学员：
- 报名时会自动进行资格校验
- 需要符合年龄、体重等要求
- 会自动分配到对应的子组

### 3. 分组规则不可随意修改

- 比赛创建后，不建议修改分组规则
- 修改规则不会影响已报名的学员
- 但可能导致新老学员分组不一致
