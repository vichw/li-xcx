# 添加成人组分组配置

## 📋 修改内容

在 `code/比赛分组规则配置数据.json` 中新增**成人组**分组规则。

## ✅ 成人组配置详情

### 基本信息
- **组别代码**: `adult`
- **组别名称**: 成人组
- **年龄范围**: 17岁及以上（`age_min: 17, age_max: 999`）
- **性别分组**: 是（`gender_separated: true`）

### 体重级别（男女相同）

成人组采用统一的体重分级标准，男女都使用相同的体重级别：

| 体重级别 | 代码 | 上限（kg） |
|---------|------|-----------|
| -45kg级 | w45  | 45 |
| -50kg级 | w50  | 50 |
| -55kg级 | w55  | 55 |
| -60kg级 | w60  | 60 |
| -65kg级 | w65  | 65 |
| -70kg级 | w70  | 70 |
| -75kg级 | w75  | 75 |
| -80kg级 | w80  | 80 |
| +80kg级 | w80plus | 999 |

**共计**：9个体重级别

### 子组总数

- **成人男子组**: 9个子组（9个体重级别）
- **成人女子组**: 9个子组（9个体重级别）
- **成人组合计**: 18个子组

## 🎯 设计说明

### 1. 年龄定义
- **成人组**：17岁及以上（包括17岁）
- 与高中组（15-16岁）无缝衔接，避免年龄空档

### 2. 体重级别简化
成人组的体重级别相比高中组更简洁：
- **高中组**：10个级别（间隔3-5kg）
- **成人组**：9个级别（间隔5kg）
- 原因：成人体重更稳定，使用更大间隔便于管理

### 3. 男女统一标准
- 成人组男女使用相同的体重级别
- 符合国际跆拳道竞赛惯例
- 简化管理和配置

## 🔄 与现有系统的集成

### 数据库影响
1. **无需修改数据库结构** - 使用现有的 `competition_group_configs` 集合
2. **导入配置** - 可通过管理后台的"分组规则配置"页面导入此JSON

### 云函数自动支持
现有的 `calculateGroup` 函数会自动识别成人组：
- 年龄17岁+ → 查找 `adult` 年龄组
- 根据性别 → 匹配 `male` 或 `female`
- 根据体重 → 匹配对应的体重级别

### 前端显示
- 小程序报名时，17岁及以上的学员会自动提示"成人组"
- 管理后台会显示成人组的分组统计和对战表

## 🚀 部署建议

### 导入配置到系统
1. 登录管理后台
2. 进入"分组规则配置"页面
3. 点击"新建配置"
4. 复制完整的JSON内容
5. 保存配置

### 创建成人组比赛
1. 进入"比赛管理"
2. 点击"新建比赛"
3. 在"分组规则"下拉框中选择"标准跆拳道分组规则"
4. 系统会自动识别成人组参赛者

## ⚠️ 注意事项

1. **年龄界限**
   - 16岁及以下 → 高中组
   - 17岁及以上 → 成人组
   
2. **体重测量**
   - 成人组体重间隔5kg，测量需更精确
   - 建议赛前称重并记录

3. **兼容性**
   - 现有系统无缝支持，无需修改代码
   - 旧的比赛不受影响

4. **数据验证**
   - 报名时系统会自动验证年龄和体重
   - 不符合任何组别的会提示详细原因
