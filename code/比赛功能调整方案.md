# 比赛功能调整方案

## 📋 需求变更总结

### 管理端变更
1. **比赛字段调整**：
   - ✅ 保留：赛事名称、开始日期、结束日期

## 📝 注意事项

### 1. 数据迁移
- 现有比赛数据需要添加 `registration_status` 字段（默认值：closed）
- 现有比赛数据需要添加 `registration_count` 字段（默认值：0）

### 2. 权限控制
- 报名功能需要用户授权登录
- 每个用户每场比赛只能报名一次

### 3. 业务逻辑
- 报名关闭后不允许新的报名
- 已生成对战表后不允许修改参赛学生
- 比赛结束后不允许修改对战结果

### 4. 小程序限制
- 报名表单需要校验
- 体重需要合理范围（20-150kg）
- 年龄需要合理范围（5-100岁）

## 🔄 与原设计的主要差异

| 项目 | 原设计 | 新设计 |
|------|--------|--------|
| 参赛资格 | 按级别自动筛选 | 手动报名 + 管理员筛选 |
| 学员来源 | students 表 | competition_registrations 表 |
| 比赛字段 | 包含 grade | 移除 grade，新增 registration_status |
| 报名流程 | 无 | 学生主动报名 |
| 管理流程 | 直接生成对战表 | 报名管理 → 选择参赛者 → 生成对战表 |
