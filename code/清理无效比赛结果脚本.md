# 清理无效比赛结果脚本

## 问题说明

在比赛结果页面，显示了一条无效的结果数据（student_name 为 "define"，没有年龄和体重信息）。这是因为数据库中有脏数据。

## 已修复

已修改云函数的 `getResults` 和 `getCompetitionDetail` 方法，会自动过滤掉无效数据：
- 没有 `student_id` 的记录
- 没有 `student_name` 的记录
- 没有 `rank` 的记录

## 清理数据库中的脏数据

### 方法1：在云开发控制台执行（推荐）

1. 进入云开发控制台
2. 选择"数据库" → "competition_results" 集合
3. 点击右上角的"高级操作"
4. 执行以下脚本：

```javascript
// 查看所有无效的结果记录
db.collection('competition_results')
  .where({})
  .get()
  .then(res => {
    const invalid = res.data.filter(item => 
      !item.student_id || !item.student_name || !item.rank
    );
    console.log('找到的无效记录:', invalid);
  });

// 删除所有无效的结果记录
// 注意：执行前先确认上面的查询结果
db.collection('competition_results')
  .where({})
  .get()
  .then(res => {
    const deletePromises = res.data
      .filter(item => !item.student_id || !item.student_name || !item.rank)
      .map(item => 
        db.collection('competition_results').doc(item._id).remove()
      );
    
    return Promise.all(deletePromises);
  })
  .then(results => {
    console.log('删除成功，共删除', results.length, '条记录');
  });
```

### 方法2：手动查找并删除

1. 进入云开发控制台
2. 选择"数据库" → "competition_results" 集合
3. 查看所有记录，找到以下特征的记录：
   - `student_name` 为 "define" 或为空
   - `student_id` 为空
   - `rank` 为空或0
4. 点击该记录右侧的删除按钮
5. 确认删除

## 预防措施

已在云函数中添加了数据验证，现在：

### getResults 方法
```javascript
// 过滤掉无效数据
const validResults = results.data.filter(result => 
  result.student_id && result.student_name && result.rank
);
```

### getCompetitionDetail 方法
```javascript
// 过滤掉无效数据
results = (resultsResult.data || []).filter(result => 
  result.student_id && result.student_name && result.rank
);
```

## 如何避免产生脏数据

在管理端设置比赛结果时：
1. 确保选择了有效的学员
2. 确保设置了正确的名次
3. 不要手动在数据库中创建记录

## 验证清理效果

清理后，在小程序端：
1. 进入比赛详情页面
2. 选择一个子组
3. 点击"比赛结果"tab
4. 应该看不到异常的 "define" 记录了

## 如果问题依然存在

1. 检查云函数是否已重新部署
2. 在云开发控制台检查 `competition_results` 集合
3. 手动删除所有无效记录
4. 重启小程序

---

**重要提示**：
- 删除数据前建议先备份
- 可以先执行查询语句确认要删除的数据
- 删除后无法恢复
