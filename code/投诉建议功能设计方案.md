# 投诉&建议功能设计方案

## 📋 功能概述

为跆拳道培训小程序添加投诉建议模块，让学员/家长能够方便地反馈问题和提出建议，管理端能够及时处理和回复。

---

## 🎯 用户场景分析

### 典型投诉场景

1. **教学质量类**
   - 教练态度问题（迟到、责任心不够）
   - 教学方法不当（过于严格/松散）
   - 课程内容与宣传不符
   - 学生受伤未及时处理

2. **场馆设施类**
   - 训练器材损坏（护具、脚靶）
   - 卫生问题（更衣室、垫子）
   - 安全隐患（地面湿滑、设备老化）
   - 空调/通风问题

3. **服务管理类**
   - 前台服务态度差
   - 课程通知不及时
   - 请假/补课不方便
   - 退费/转班问题

4. **考级比赛类**
   - 考级费用争议
   - 比赛安排不合理
   - 成绩评定有异议
   - 证书颁发延迟

5. **收费相关**
   - 费用说明不清
   - 额外收费
   - 退费流程复杂

### 典型建议场景

1. **课程改进**
   - 增加课程类型（少儿班、成人班）
   - 调整上课时间
   - 增加私教课程

2. **设施改进**
   - 增加训练设备
   - 改善更衣室条件
   - 增加休息区

3. **活动组织**
   - 组织亲子活动
   - 增加对外交流
   - 举办内部比赛

4. **管理优化**
   - 优化请假流程
   - 改进通知方式
   - 提供线上视频课

## 💾 数据库设计

### feedback 集合（投诉建议表）

```json
{
  "_id": "反馈ID",
  "type": "complaint/suggestion",  // 投诉/建议
  "category": "教学质量/场馆设施/服务管理/考级比赛/收费相关/其他",
  "title": "标题（简短描述）",
  "content": "详细描述",
  "images": ["图片URL1", "图片URL2"],  // 可选，最多3张
  
  // 提交人信息
  "user_openid": "用户openid",
  "user_name": "提交人姓名",
  "user_phone": "联系电话",
  "is_anonymous": false,  // 是否匿名
  
  // 处理信息
  "status": "pending/processing/resolved/closed",  // 待处理/处理中/已解决/已关闭
  "priority": "normal/high/urgent",  // 优先级（可选）
  "admin_reply": "管理员回复内容",
  "admin_name": "处理人姓名",
  "reply_time": "回复时间",
  
  // 满意度（可选）
  "satisfaction": 5,  // 1-5星
  "satisfaction_comment": "满意度评价",
  
  // 时间戳
  "create_time": "提交时间",
  "update_time": "更新时间"
}
```

### 索引建议
```javascript
db.collection('feedback').createIndex({ "user_openid": 1, "create_time": -1 })
db.collection('feedback').createIndex({ "status": 1, "create_time": -1 })
db.collection('feedback').createIndex({ "type": 1, "category": 1 })
```

## 📱 小程序端功能

### 1. 入口设计

**位置**: "我的"页签中

```
我的页面
├─ 个人信息
├─ 我的荣誉
├─ 考级历史
├─ 投诉建议  ← 新增入口
└─ 设置
```

### 2. 功能页面

#### 2.1 投诉建议列表页
- **路径**: `/pages/taekwondo/feedback-list/index`
- **功能**:
  - Tab切换：全部 / 待处理 / 已处理
  - 列表展示：类型标签、标题、状态、提交时间
  - 点击查看详情
  - 右上角"+"按钮，提交新投诉/建议

#### 2.2 提交投诉建议页
- **路径**: `/pages/taekwondo/feedback-submit/index`
- **表单字段**:
  - 类型选择：投诉 / 建议
  - 类别选择：教学质量 / 场馆设施 / 服务管理 / 考级比赛 / 收费相关 / 其他
  - 标题输入：简短描述问题（必填，30字内）
  - 详细描述：详细说明（必填，500字内）
  - 图片上传：最多3张（可选）
  - 联系方式：电话（必填）
  - 匿名选项：是否匿名提交（可选）
  - 提交按钮

#### 2.3 投诉建议详情页
- **路径**: `/pages/taekwondo/feedback-detail/index`
- **内容**:
  - 基本信息：类型、类别、标题
  - 详细描述
  - 图片（如有）
  - 提交时间
  - 状态标签
  - 管理员回复（如有）
  - 回复时间（如有）
  - 满意度评价（已解决后可评）

- **功能**:
  - 筛选：

    - 类别：全部 / 教学质量 / 场馆设施 / 服务管理 / 考级比赛 / 收费相关 / 其他
    - 状态：全部 / 待处理 / 处理中 / 已解决 / 已关闭

  - 保存按钮

## 🔌 云函数接口设计

### 云函数名：feedbackFunctions

#### 1. submitFeedback（提交投诉建议）
```javascript
参数: {
  type: 'complaint' | 'suggestion',
  category: string,
  title: string,
  content: string,
  images: string[],
  user_phone: string,
  is_anonymous: boolean
}
返回: {
  success: boolean,
  feedback_id: string
}
```

#### 2. getFeedbackList（获取投诉列表 - 用户端）
```javascript
参数: {
  status?: string,  // 筛选状态
  limit: number,
  skip: number
}
返回: {
  success: boolean,
  data: Feedback[],
  total: number
}
```

#### 3. getFeedbackDetail（获取详情）
```javascript
参数: {
  feedback_id: string
}
返回: {
  success: boolean,
  data: Feedback
}
```

#### 4. getAllFeedbacks（获取所有投诉 - 管理端）
```javascript
参数: {
  type?: string,
  category?: string,
  status?: string,
  start_date?: string,
  end_date?: string,
  limit: number,
  skip: number
}
返回: {
  success: boolean,
  data: Feedback[],
  total: number,
  statistics: {
    pending: number,
    todayNew: number
  }
}
```

#### 5. updateFeedback（处理投诉 - 管理端）
```javascript
参数: {
  feedback_id: string,
  status: string,
  admin_reply: string,
  admin_name: string
}
返回: {
  success: boolean
}
```

#### 6. rateFeedback（满意度评价 - 用户端）
```javascript
参数: {
  feedback_id: string,
  satisfaction: number,  // 1-5
  satisfaction_comment: string
}
返回: {
  success: boolean
}
```

## 🎨 状态流转

```
提交 → 待处理 → 处理中 → 已解决
                  ↓
                已关闭（无需处理）
```

**状态说明**:
- **待处理**: 刚提交，等待管理员处理
- **处理中**: 管理员已查看，正在处理
- **已解决**: 问题已解决，用户可评价
- **已关闭**: 问题无效或不予处理

---

## 🔔 通知机制（可选）

1. **用户提交后**: 管理端显示待处理数量提醒
2. **管理员回复后**: 小程序发送订阅消息通知用户

## ❓ 需要确认的问题

### 1. 匿名功能
- **是否允许匿名提交？**
  - 优点：用户更愿意反馈真实问题
  - 缺点：难以进一步沟通

### 2. 图片上传
- **是否需要上传图片？**
  - 优点：问题更直观（设备损坏、卫生问题）
  - 缺点：需要云存储空间

### 3. 满意度评价
- **是否需要用户评价处理结果？**
  - 优点：了解服务质量
  - 缺点：增加用户操作步骤

### 4. 优先级
- **是否需要优先级标记？**
  - 紧急、重要、普通
  - 管理员可手动调整

### 5. 类别设置
- **是否使用以上建议的类别？**
  - 教学质量 / 场馆设施 / 服务管理 / 考级比赛 / 收费相关 / 其他
  - 或者您有其他类别建议？
