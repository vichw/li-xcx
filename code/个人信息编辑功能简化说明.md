# 个人信息编辑功能简化说明

## 简化内容

### 1. 编辑字段调整

**简化前**：
- 姓名
- 段位/级别（选择器）
- 入馆日期（日期选择器）
- 头像

**简化后**：
- 姓名
- 头像

### 2. 移除的字段说明

#### 段位/级别
- **移除原因**：段位/级别信息应该由系统根据考级情况自动更新，用户不应手动修改
- **数据来源**：段位信息通过考级系统自动更新到 `students` 表的 `grade` 字段

#### 入馆日期
- **移除原因**：入馆日期应该使用会员开始日期（`membership_start_date`），由系统在用户缴费成功后自动设置
- **数据来源**：入馆日期使用 `students` 表的 `membership_start_date` 字段

### 3. 保留的字段说明

#### 姓名
- **保留原因**：用户基本信息，需要用户主动维护
- **数据来源**：`students` 表的 `name` 字段

#### 头像
- **保留原因**：用户个性化信息，需要用户主动上传
- **数据来源**：`students` 表的 `avatar` 字段

## 代码修改详情

### 1. WXML 模板简化

**简化前**：
```xml
<view class="edit-form">
  <view class="form-item">
    <text class="form-label">姓名</text>
    <input class="form-input" value="{{formData.name}}" data-field="name" bindinput="inputFormField" placeholder="请输入姓名" />
  </view>
  <view class="form-item">
    <text class="form-label">段位/级别</text>
    <picker class="form-picker" range="{{beltOptions}}" value="{{beltIndex}}" bindchange="onBeltChange">
      <view class="picker-content">{{formData.grade || '请选择段位/级别'}}</view>
    </picker>
  </view>
  <view class="form-item">
    <text class="form-label">入馆日期</text>
    <picker class="form-picker" mode="date" value="{{formData.joinDate}}" data-field="joinDate" bindchange="inputFormField">
      <view class="picker-content">{{formData.joinDate || '请选择日期'}}</view>
    </picker>
  </view>
</view>
```

**简化后**：
```xml
<view class="edit-form">
  <view class="form-item">
    <text class="form-label">姓名</text>
    <input class="form-input" value="{{formData.name}}" data-field="name" bindinput="inputFormField" placeholder="请输入姓名" />
  </view>
</view>
```

### 2. JavaScript 数据结构简化

**简化前**：
```javascript
formData: {
  name: '',
  age: '',
  grade: '', // 段位/级别
  joinDate: '', // 入馆日期
  avatar: '', // 头像URL
  gradeImg: '' // 对应的等级图片
},

beltIndex: 0,
```

**简化后**：
```javascript
formData: {
  name: '',
  avatar: '' // 头像URL
},
```

### 3. 表单验证优化

**简化前**：
```javascript
// 表单验证
if (!formData.name) {
  wx.showToast({
    title: '请输入姓名',
    icon: 'none'
  });
  return;
}
```

**简化后**：
```javascript
// 表单验证
if (!formData.name || formData.name.trim() === '') {
  wx.showToast({
    title: '请输入姓名',
    icon: 'none'
  });
  return;
}
```

### 4. 表单提交数据优化

**简化前**：
```javascript
userInfo: {

  phoneNumber: this.data.phoneNumber
}
```

**简化后**：
```javascript
userInfo: {
  name: formData.name,
  avatar: formData.avatar,
  phoneNumber: this.data.phoneNumber

```

## 数据流程说明

### 1. 姓名数据流程
1. **显示**：从 `students` 表的 `name` 字段读取
2. **编辑**：用户在表单中输入
3. **保存**：通过 `updateUserInfo` 云函数更新到 `students` 表
4. **显示**：更新后的姓名在会员信息中显示

### 2. 头像数据流程
1. **显示**：从 `students` 表的 `avatar` 字段读取
2. **编辑**：用户点击"更换头像"上传新图片
3. **保存**：头像URL通过 `updateUserInfo` 云函数更新到 `students` 表
4. **显示**：更新后的头像在用户信息区域显示

### 3. 段位信息数据流程
1. **来源**：通过考级系统自动更新
2. **显示**：在用户信息区域显示当前段位
3. **更新**：考级成功后自动更新 `students` 表的 `grade` 字段

### 4. 入馆日期数据流程
1. **来源**：用户缴费成功后自动设置
2. **显示**：在会员信息中显示 `membership_start_date`
3. **更新**：支付回调时自动更新 `students` 表的 `membership_start_date` 字段
