## 🚀 部署步骤

### 第一步：创建数据库集合

在**腾讯云开发控制台** → **数据库** 中创建以下3个集合：

#### 1. competitions (比赛表)
```json
{
  "_id": "自动生成",
  "name": "赛事名称",
  "start_date": "开始日期",
  "end_date": "结束日期",
  "grade": "级别",
  "status": "状态",
  "top_display_count": 3,
  "participant_count": 0,
  "bracket_generated": false,
  "create_time": "创建时间",
  "update_time": "更新时间"
}
```

**索引设置：**
- 字段：`grade`，类型：升序
- 字段：`status`，类型：升序

#### 2. competition_brackets (对战表)
```json
{
  "_id": "自动生成",
  "competition_id": "比赛ID",
  "round": 1,
  "match_no": 1,
  "position": "R1-M1",
  "student1_id": "学员1 ID",
  "student1_name": "学员1姓名",
  "student1_avatar": "学员1头像",
  "student2_id": "学员2 ID",
  "student2_name": "学员2姓名",
  "student2_avatar": "学员2头像",
  "winner_id": "获胜者ID",
  "winner_name": "获胜者姓名",
  "score": "比分",
  "create_time": "创建时间"
}
```

**索引设置：**
- 字段：`competition_id`，类型：升序
- 字段：`round`，类型：升序

#### 3. competition_results (比赛结果表)
```json
{
  "_id": "自动生成",
  "competition_id": "比赛ID",
  "student_id": "学员ID",
  "student_name": "学员姓名",
  "student_avatar": "学员头像",
  "rank": 1,
  "create_time": "创建时间"
}
```

**索引设置：**
- 字段：`competition_id`，类型：升序
- 字段：`rank`，类型：升序

### 第二步：上传云函数

#### 方法一：使用微信开发者工具

1. 打开微信开发者工具
2. 进入云开发控制台
3. 找到 `cloudfunctions/competitionFunctions` 文件夹
4. 右键点击 → **上传并部署：云端安装依赖**
5. 等待上传完成

#### 方法二：使用命令行（如果有配置）

```bash
cd code/cloudfunctions/competitionFunctions
npm install
# 然后在微信开发者工具中右键上传
```

**验证云函数：**
```javascript
// 在微信开发者工具控制台测试
wx.cloud.callFunction({
  name: 'competitionFunctions',
  data: {
    type: 'getCompetitions',
    limit: 10
  },
  success: res => {
    console.log('云函数测试成功:', res);
  }

```

### 第三步：部署管理端

#### 1. 安装依赖（如果还没安装）

```bash
cd manager/taekwondo-admin
npm install
```

#### 2. 配置云开发环境ID

确保 `src/utils/cloudbase.js` 中配置了正确的环境ID：

```javascript
const app = cloudbase.init({
  env: 'your-env-id' // 替换为您的环境ID
});
```

#### 3. 本地测试

```bash
npm run dev
```

访问 `http://localhost:5173/` 测试功能：
- 登录：admin / admin123
- 进入"比赛管理"菜单
- 测试创建比赛、生成对战表等功能

#### 4. 构建生产版本

```bash
npm run build
```

#### 5. 部署到服务器

将 `dist` 文件夹内容部署到您的服务器。

## 🔍 常见问题排查

### 问题1：云函数调用失败

**症状：** 调用云函数返回错误

**解决方案：**
1. 检查云函数是否已上传
2. 检查环境ID是否正确
3. 在云开发控制台查看云函数日志
4. 确认数据库集合已创建

### 问题2：对战表生成失败

**症状：** 点击生成对战表没有反应或报错

**可能原因：**
1. 同级别学员数量不足（至少需要2人）
2. 学员状态不是"激活"或"正常"

**解决方案：**
1. 检查students表中对应级别的学员数据
2. 确保学员的 `isActive=true` 且 `status="正常"`
3. 查看云函数日志排查具体错误

### 问题3：小程序页面空白

**症状：** 打开比赛列表或详情页面显示空白

**解决方案：**
1. 检查控制台是否有报错
2. 确认页面路径是否在app.json中注册
3. 检查云函数是否正常返回数据
4. 确认网络请求权限

### 问题4：管理端无法访问

**症状：** 管理端页面404或白屏

**解决方案：**
1. 检查路由配置是否正确
2. 确认组件导入路径
3. 查看浏览器控制台错误
4. 检查cloudbase配置

## 📞 技术支持

如遇到问题，请检查：

1. **云开发控制台** → **日志** 查看云函数执行日志
2. **微信开发者工具** → **控制台** 查看小程序错误
3. **浏览器开发者工具** → **控制台** 查看管理端错误

常见错误码：
- `-1`: 系统错误，检查云函数代码
- `-501004`: 数据库请求失败，检查集合是否存在
- `-404`: 云函数不存在，检查是否已上传
