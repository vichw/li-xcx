# 报名流程修改说明

## 修改概述

已将在线报名流程从"报名缴费生效"模式改为"报名审核生效"模式，移除了自动缴费功能，改为管理员审核制。

## 修改详情

### 1. 云函数修改

#### submitRegistration 云函数 (已修改)
**文件路径**: code/cloudfunctions/taekwondoFunctions/submitRegistration/index.js

**主要变更**:
- 移除了缴费相关逻辑
- 创建报名记录时状态改为"待审核"
- 更新了状态检查逻辑，新增以下状态码：
  - PENDING_REVIEW: 待审核
  - APPROVED: 审核通过
  - REJECTED: 审核拒绝
  - ALREADY_MEMBER: 已是有效会员
- 修改返回信息为审核提示

### 2. 小程序页面修改

#### register/index.js (已修改)
**文件路径**: code/miniprogram/pages/taekwondo/register/index.js

**主要变更**:
- 移除了所有缴费相关方法：
  - showPaymentDialog()
  - hidePaymentDialog()
  - createPaymentOrder()
  - startPayment()
  - cancelExistingOrder()
  - checkOrderStatus()
- 简化了submitRegistration()方法的处理逻辑
- 更新了错误码处理，支持新的审核状态码
- 报名成功后直接显示审核提示

#### register/index.wxml (已修改)
**文件路径**: code/miniprogram/pages/taekwondo/register/index.wxml

**主要变更**:
- 移除了整个缴费弹窗模板（第85-121行）
- 保留了三种报名方式：电话报名、在线报名、微信报名

### 3. 删除的云函数

以下云函数已被删除，因为不再需要缴费功能：
- createRegistrationPayment/ - 创建报名缴费订单
- egistrationPaymentCallback/ - 报名缴费回调处理
- checkRegistrationOrderStatus/ - 查询报名订单状态
- cancelRegistrationOrder/ - 取消报名订单

### 4. 数据库状态变更

#### registrations 表状态字段
**原状态值**:
- 待缴费
- 已缴费

**新状态值**:
- 待审核 - 用户提交报名后的初始状态
- 审核通过 - 管理员审核通过
- 审核拒绝 - 管理员审核拒绝

## 新的用户流程

### 用户端体验
1. 用户输入手机号提交报名
2. 系统显示"报名申请提交成功，请等待管理员审核"
3. 用户等待审核结果
4. 审核通过后可正常登录使用系统

### 管理员工作流程
1. 查看待审核的报名列表
2. 审核报名申请（通过/拒绝）
3. 审核通过后系统自动创建学员记录

## 保留的功能

以下功能未受影响，仍正常工作：
- 考级缴费功能（createGradeExamOrder等）
- VIP会员缴费功能（createVipPayment等）
- 学员管理功能
- 荣誉管理功能
- 电话报名和微信报名方式
