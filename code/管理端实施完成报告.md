## 💡 技术亮点

### 1. 动态表单切换
根据"启用自动分组"开关，动态显示/隐藏不同字段：
- 自动分组：显示分组规则选择器
- 传统模式：显示年龄体重范围输入框

### 2. 动态表单验证
使用 Element Plus 的自定义验证器，根据分组模式动态验证：
```javascript
group_config_id: [
  { 
    validator: (rule, value, callback) => {
      if (formData.enable_auto_grouping && !value) {
        callback(new Error('请选择分组规则'))
      } else {
        callback()
      }
    }
  }
]
```

### 3. 按年龄组分组展示
使用计算属性将扁平的子组列表转换为按年龄组分组的结构：
```javascript
const groupedSubGroups = computed(() => {
  const grouped = {};
  subGroups.value.forEach(subGroup => {
    const key = subGroup.age_group_name;
    if (!grouped[key]) {
      grouped[key] = { sub_groups: [] };
    }
    grouped[key].sub_groups.push(subGroup);
  });
  return Object.values(grouped);
});
```

### 4. URL参数传递
支持通过URL参数直接跳转到指定子组：
```javascript
// 从分组管理跳转到对战表管理
router.push({
  name: 'CompetitionBracket',
  params: { id: competitionId },
  query: { sub_group_id: subGroup.sub_group_id }
});

// 页面加载时读取URL参数
const selectedSubGroupId = ref(route.query.sub_group_id || '');
```

### 5. 批量操作反馈

```javascript
if (error_count > 0) {
```

## 📝 使用说明

### 首次使用流程

#### 第1步：导入默认分组规则
```bash
# 使用 code/比赛分组规则配置数据.json
# 在云开发控制台导入到 competition_group_configs 集合
```

#### 第2步：创建自动分组比赛
1. 进入管理后台
2. 点击"比赛管理" → "新建比赛"
3. 填写比赛信息
4. 开启"启用自动分组"
5. 选择"标准跆拳道分组规则"
6. 保存比赛

#### 第3步：等待学员报名
学员在小程序端报名后会自动分组到对应子组

#### 第4步：管理分组和生成对战表
1. 进入该比赛的"分组管理"
2. 查看各子组的报名情况
3. 点击"一键生成所有对战表"
4. 或为单个子组单独生成

#### 第5步：录入对战结果
1. 点击某个子组的"对战表管理"
2. 录入每场对战的比分和获胜者
3. 系统自动计算下一轮对阵

#### 第6步：设置最终排名
1. 点击某个子组的"结果管理"
2. 为学员设置名次
3. 保存结果

### 自定义分组规则

如需自定义分组规则：
1. 进入"分组规则配置"
2. 点击"新建规则"
3. 设置年龄组：
   - 代码（英文，如 high_school）
   - 名称（中文，如 高中组）
   - 年龄范围（如 15-16）
4. 配置体重级别：
   - 是否区分男女
   - 添加各个级别（代码、标签、最大体重）
5. 保存规则
6. 在创建比赛时选择该规则

## ⚠️ 注意事项

### 1. 模式切换限制
- 比赛创建后不建议更改分组模式
- 如需更改，请确保没有学员报名

### 2. 分组规则修改
- 修改分组规则不会影响已创建的比赛
- 建议为重要比赛创建专用规则

### 3. 对战表生成
- 每个子组至少需要2人才能生成对战表
- 人数不足的子组会跳过
- 支持2-64人的淘汰赛制

### 4. 结果录入
- 必须从第一轮开始依次录入
- 上一轮未完成，下一轮无法编辑
- 轮空自动晋级

### 5. 性能考虑
- 单个比赛建议不超过50个子组
- 子组较多时使用"一键生成"而非逐个生成
