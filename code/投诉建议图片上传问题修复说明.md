# 投诉建议图片上传问题修复说明

## 🐛 问题描述

### 错误信息
```
TypeError: Cannot read property 'length' of undefined
at chooseImage (index.js:153)
```

### 问题场景
在小程序提交投诉建议页面，点击"添加图片"按钮时，程序报错无法上传图片。

---

## 🔍 问题分析

### 数据结构
```javascript
Page({
  data: {
    feedbackType: 'complaint',
    categories: [],
    formData: {
      category: '',
      title: '',
      content: '',
      images: [],      // ✅ images 在 formData 里面
      user_name: '',
      user_phone: ''
    },
    maxImages: 5       // ✅ maxImages 在 data 顶层
  }
})
```

### 错误代码
```javascript
async chooseImage() {
  // ❌ 错误：从 this.data 直接解构 images
  const { images, maxImages } = this.data;
  
  // images 是 undefined，访问 length 会报错
  if (images.length >= maxImages) {  // ❌ TypeError
    // ...
  }
}
```

### 问题根源
- `images` 不在 `data` 的顶层
- `images` 在 `data.formData.images` 中
- 直接从 `this.data` 解构 `images` 得到 `undefined`
- 尝试访问 `undefined.length` 导致错误

---

## ✅ 修复方案

### 修复代码
```javascript
async chooseImage() {
  // ✅ 正确：从正确的路径获取 images
  const { maxImages, formData } = this.data;
  const images = formData.images || [];  // 添加默认值保护
  
  if (images.length >= maxImages) {
    wx.showToast({
      title: `最多上传${maxImages}张图片`,
      icon: 'none'
    });
    return;
  }
  
  try {
    const res = await wx.chooseImage({
      count: maxImages - images.length,
      sizeType: ['compressed'],
      sourceType: ['album', 'camera']
    });
    
    this.uploadImages(res.tempFilePaths);
  } catch (error) {
    console.error('选择图片失败:', error);
  }
}
```

### 修复要点

#### 1. 正确获取 images
```javascript
// 错误 ❌
const { images } = this.data;

// 正确 ✅
const images = this.data.formData.images;

// 更安全 ✅✅
const images = this.data.formData.images || [];
```

#### 2. 正确的解构方式
```javascript
// 方式1：分步获取
const { formData, maxImages } = this.data;
const images = formData.images || [];

// 方式2：直接访问
const images = this.data.formData.images || [];
const maxImages = this.data.maxImages;
```
